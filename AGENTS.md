# Project guidance

- This is a private Web + macOS prototype of くじらの散歩道. The user explicitly requested a local Mac app. Use standard AppKit/CoreGraphics/JavaScriptCore with the shared TypeScript world; no added third-party runtime. The user additionally authorized the Fighters MVP: one stage, two placeholder enemies and one fictional boss, auto/manual, combos/dodge/special, and return to quiet life; follow docs/fighters-mvp.md. No publishing, GitHub deployment, analytics, AI/API integration, or added audio. Keep that roster for auto/manual. The 2026-11-12 update additionally authorizes an opt-in endless boss rush: existing Lumie plus two code-only rivals, four fixed stages, and the DSH API described in docs/endless-boss-rush.md. Those additions belong only to endless; do not expand the auto/manual roster.
- Local app packaging is authorized for personal preview, not public distribution or verified third-party art rights. Keep generated art/app/ZIP outputs ignored, preserve pending permissions, and require explicit local-preview build mode. First launch opens preview only. Wallpaper ON is a user action; never change system wallpaper preferences or enable login autostart during build/tests.
- The user approved the fin-ear v02 design and authorized implementation. A local 80×112, sixteen-frame production atlas and sunset scene are integrated through the art-profile alias. Follow `docs/art-direction.md`; keep the accepted identity. Do not replace it with the rejected programmatic placeholder or add official logos/third-party files.
- Wallpaper-first brush-up is authorized: the approved 480×270 scene and 16 frames stay pixel-identical inside a 1024×576 local wide matte (center at 272,153), the wallpaper draws at a whole-number scale >=2, and ambient life is code-only rect commands. Automatic Fighters events are an auto-piloted terrace bout (`route 'arena'`, camera 960 fixed, no HUD/banners/boss, joined mid-fight with reinforcements, about 30 seconds) that returns to the quiet study; the old in-study room incident is internal regression data only. The user explicitly asked for this over the former room-only incident. The manual/preview entry now uses a fixed terrace arena (`route 'arena'`, camera 960), two small-enemy rounds then one one-on-one boss, with safe introductions/intermission and return home; the old 4-area route is legacy test data only. Do not turn the wallpaper back into a scrolling game surface; the bout keeps the fixed camera and no input.
- Three selectable backgrounds are authorized locally: sunset (the approved scene), night and rain. Each is 480×270 with its own 1024×576 matte generated from the same approved layout; they are GPT-Image-assisted local-only art (no third-party files, no publication). Background choice is persisted as the fifth personal setting. Character attribution belongs to the original DeepSeek-chan fan creators; this project claims no rights and grants no license.
- The user requested synchronization to the private repository `lero003/deepseek-chan-wallpaper`. Keep it private and push only on explicit sync requests. Do not change visibility or enable Pages. Publication remains blocked until character-design and per-asset permissions are documented.
- The 2026-11-12 follow-up authorizes reviewed source pushes and individual preview Releases in private repositories. Keep visibility unchanged; the DSH plugin archive uses its separate placeholder build and never uploads the ignored private-art client. This is not public distribution or permission to publish the character/assets. Existing published tags stay immutable.
- `private-art/` contains reference studies, generated masters, local production sprites/scene/manifest, and QA images. The design is approved for local implementation, not for publication. It is ignored by Git; never force-add it. Vite selects its runtime module if present; `--mode placeholder` must always select the committed fallback without private imports.
- The user requested fighting-action brush-up: replace the existing boss slot with one original AI-inspired girl, not additional bosses in the manual/automatic arena. The later opt-in endless roster is a separate authorized mode (docs/endless-boss-rush.md). 綴星リュミエ is a Claude-inspired, non-official local design proposal; its generated eight-pose atlas stays ignored and pending permission. Keep the approved heroine/scene bytes unchanged. Optional rival art failures use shared code-only fallback, and placeholder builds never import private art.
- Arcade rules are local to the manual arena: 90s per round, score from effective damage/KO/combo/clear bonuses, S/A/B/C rank from damage and continues, TIME UP uses the same retry as defeat, and a failed round's points roll back to the last cleared checkpoint while CONTINUE count stays. Keep raw runStats untouched for diagnostics; never derive score from them. The wallpaper/room incident and legacy routes must never earn score or spend the arcade clock.
- TypeScript + Canvas 2D is deliberate; keep the simulation independent of the browser and renderer. Use a fixed simulation step and seeded randomness only at behavior transitions.
- Node >=22.18 runs the built-in unit test runner. npm is the local package manager. Read package definitions, the lockfile, and scripts before dependency actions; install with lifecycle scripts disabled.
- Do not install or restore Playwright or dedicated automated browsers, including through transitive dependencies or temporary commands. Use unit tests, typechecking, build checks, and manual testing in an existing normal browser.
- Run `npm run check` and `npm run build` after meaningful changes. `npm run assets:check` verifies byte-for-byte reproducibility and the asset ledger. The mac scripts pass `--disable-sandbox` to SwiftPM because this local package has no dependencies/plugins and some agent environments block nested sandboxes.
- Committed fallback art lives in `assets/`, generated by `scripts/generate-art.mjs`. Approved local production masters, processing scripts, runtime art and provenance live under ignored `private-art/`. `npm run assets:generate` only regenerates fallback art. Keep code/art terms separate; no redistribution license has been chosen.
- An initial/resize still paint while hidden is intentional: it avoids an empty canvas, never advances the world/starts a timer, and is blocked while suspended.
- Native WebKit smoke needs a genuinely visible page for animation assertions. This environment reports its test windows as hidden/occluded; do not weaken app visibility/sleep guards to make that check pass, or claim full native/Safari/Chrome verification from partial snapshots.
- No secrets or `.env` files are needed. The Vite config disables env-directory loading. Keep reports temporary; do not inspect personal folders or browser profiles.
- At handoff, update `docs/current_status.md` with actual checks and unverified manual acceptance items.
