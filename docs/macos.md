# Mac版 — 個人用ローカル試作

## 方針

AppKit／CoreGraphics／JavaScriptCoreだけを使うMacホスト。Web版のTypeScriptの世界・アトラス・描画コマンドをIIFEへビルドし、その同じコードをJavaScriptCoreで実行する。別言語へ行動ロジックを複製しない。HTMLやブラウザーを常駐させず、Webサーバー・Node.js・ネット接続はアプリ実行に不要。

- 初回起動はプレビューのみ。壁紙ONはユーザー操作で選ぶ。壁紙ON状態は次の起動へ自動復元しない。
- 主画面のみ。デスクトップ背景より上・アイコンより下のクリック透過NSPanelを使う。
- 元の壁紙のURL取得・コピー・設定変更を行わない。OFF・終了・クラッシュ時にアプリ所有のウィンドウがなくなれば、元の壁紙がそのまま見える方式。
- メニューバーでプレビュー・壁紙ON/OFF・一時停止・省電力・クレジット・終了を操作する。
- 通常30fps、手動またはOS低電力時15fps。Reduce Motionでは静止。画面非表示／セッション非アクティブ／スリープで時計とタイマーを止め、復帰差分を破棄する。
- 保存するのはアプリ自身の一時停止・省電力・小事件頻度・エフェクト量の4設定だけ。ゲームの進行・押下キー・壁紙ONは保存しない。音・通知・API・アクセス解析・ログイン自動起動はない。
- ファイターズMVPを追加。「遊ぶ」でプレビュー内だけを手動化。書斎→テラス→遊歩道→桟橋を歩く12セクションの横スクロールで、左右から敵が入る。壁紙は常に非アクティブ・クリック透過で、手動ゲーム中は元の生活ループを表示する。グローバルキー監視は使わない。

## ビルド

既存のNode/npm、Swift 6.2以上とmacOS SDKが必要。Swiftパッケージに外部依存はない。新しいブラウザーやnpm／Python／Swiftパッケージを自動導入しない。

```sh
# 素材がなくてもビルドできる、初期仮素材版
npm run mac:test
npm run mac:build -- --placeholder

# 明示的に許可された個人用の生成素材版（公開不可）
npm run mac:test -- --local-preview
npm run mac:build -- --local-preview
```

ローカル生成素材の使用は `--local-preview` が必要。保存済みの素材台帳・SHA-256を確認してから、必要な画像・JSON・共有コア・クレジットだけを同梱する。参考画像・生成マスター・研究資料・開発用依存・個人パスは同梱しない。

出力はGit対象外の一意なビルドフォルダーに作り、既存のアプリを削除・上書きしない。アプリ・ZIP・SHA-256・同梱ファイル台帳を記録する。ビルド時に壁紙をONにしたり、システム設定・自動起動・Gatekeeperの設定や隔離属性を変更したりしない。

## 署名と権利

個人用のローカル検証物で、Apple Developer ID署名・公証・一般配布は行わない。アドホック署名＋Hardened Runtimeを使用する。JavaScriptCoreが同梱・ハッシュ確認済みコードを動かすための `allow-jit` だけを付け、ライブラリー検証無効化・広いファイル操作ブリッジ・外部通信ブリッジは付けない。アプリがサンドボックス化されているという主張ではない。

今回の作成依頼は、個人用アプリの作成・ローカル検証への承認であり、第三者のキャラデザインや参照画像の公開・Mac配布許諾の確認ではない。既存の許諾未確認フラグを残し、公開・再配布を禁止したまま扱う。

生成された `.app` は、このMac上のローカルフォルダーで使用する。ダウンロードしたZIPから展開するとmacOSの警告が出る場合がある。アプリは未公証であり、こちらから保護設定の無効化や属性削除はしない。Apple Silicon向けのローカルビルドを前提にし、他のMac／OSバージョンでの動作保証はしない。

## 起動と停止

1. ZIPなら先に展開してアプリ全体を取り出す。アプリ内部の実行ファイルだけを移動しない。
2. アプリを開くとプレビューが出る。動きとサイズを確認する。
3. 使う場合だけ「壁紙にする」またはメニューバーの「壁紙を表示（主画面のみ）」を選ぶ。
4. OFFにすると元の壁紙が見える。プレビューを閉じてもメニューバーには残る。完全に止めるには「終了」。

## ファイターズの操作

旧版を起動している場合は終了してから新しいアプリを開く。初回表示は静かな書斎のまま。「事件を見る」でオートの雑魚→ボス→帰還をすぐ確認できる。「遊ぶ」は前面のプレビューにだけフォーカスを移す明示操作。

- WASD／矢印で左右・奥行き移動、J/Zで3段コンボ、K/Xで回避、L/Cでゲージ100の必殺。
- Escでゲームをポーズ。既存のメニュー「一時停止」は風景全体の停止で別設定。OS Reduce Motionの静止中は遊ぶ操作を無効にする。
- 「壁紙へ戻る」で入力解除・HUD消灯・帰還。勝利／敗北の「もう一度遊ぶ」で最初から再挑戦。
- 別ウィンドウ・スリープへ移ると入力を解除。手動の戦闘はフォーカス中だけ進み、壁紙側の生活は既存の可視性方針に従う。戻ると1秒の攻撃猶予。
- 小事件頻度／エフェクト量はメニューバーから。音は常時無音。主人公の専用戦闘コマ、敵・背景の完成素材は未制作（v0.4で横スクロール化・4エリア・左右湧き・敵バリエーションを追加）。

## 検証の区別

- Nodeのテスト：共有世界・描画コマンド・安全なジオメトリ・Web互換性。
- Swift Testing：素材の整合性、JavaScriptCoreとの一致、60Hz更新、15/30/60fpsの30分再生、停止復帰・低電力・静止の方針、画像とアイコン、パス制限。
- コマンドライン自己検証：署名後の実行ファイルが同梱素材と共有コアだけで起動・描画する。
- 起動スモーク：プレビューとメニューバーが生成される。壁紙はONにしない。可視アニメーション・アイコン操作・Space・実機スリープの合格とは別。
- ネイティブPNG書き出しは、実際に使う描画器の出力であって、デスクトップ画面の録画／スクリーンショットではない。

### 手動で残る受け入れ確認

- [ ] 可視状態で5分以上、待機・まばたき・歩行・反転・睡眠・自動事件と帰還を確認する。
- [ ] 手動の移動・3段攻撃・回避・必殺・敗北／再挑戦・ポーズ。押下中のアプリ切替、Command等を押しながらキーを離す操作で入力が残らない。
- [ ] 壁紙ON/OFFでアイコン・通常ウィンドウ・クリックが阻害されず、OFF／終了で元の壁紙が見える。
- [ ] Space／フルスクリーン／主画面の変更／ディスプレイ再接続が正常。
- [ ] OS低電力・Reduce Motion・一時停止・実機スリープ復帰を確認。
- [ ] 実時間30分のCPU・メモリ・発熱を測定する。シミュレーション30分テストで代用しない。
- [ ] ダウンロード・別のMac・異なるOS・Gatekeeperでの扱いを確認。公証済み配布ではない。
