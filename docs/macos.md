# Mac版 — 個人用ローカル試作

## 方針

AppKit／CoreGraphics／JavaScriptCoreだけを使うMacホスト。Web版のTypeScriptの世界・アトラス・描画コマンドをIIFEへビルドし、その同じコードをJavaScriptCoreで実行する。別言語へ行動ロジックを複製しない。HTMLやブラウザーを常駐させず、Webサーバー・Node.js・ネット接続はアプリ実行に不要。

- 初回起動はプレビューのみ。壁紙ONはユーザー操作で選ぶ。壁紙ON状態は次の起動へ自動復元しない。
- 接続中のすべてのディスプレイへ同じ世界を同期表示する。デスクトップ背景より上・アイコンより下のクリック透過NSPanelを、物理ディスプレイごとに1枚置く（ミラーリングで同一座標の場合は1枚）。
- 元の壁紙のURL取得・コピー・設定変更を行わない。OFF・終了・クラッシュ時にアプリ所有のウィンドウがなくなれば、元の壁紙がそのまま見える方式。
- メニューバーでプレビュー・壁紙ON/OFF・背景切替・一時停止・省電力・メモリ表示・クレジット・終了を操作する。メニューバー項目は壁紙ON（「くじら・壁紙」）と一時停止（pause記号）を常時表示し、ホバーで停止理由も読む。
- 通常30fps、ユーザーまたはOSの低電力時15fps。Reduce Motionでは静止。画面非表示／セッション非アクティブ／スリープで時計とタイマーを止め、復帰差分を破棄する。ステータスメニュー・設定メニューなど、いずれかのメニューを開いている間も風景は一休みし、閉じると差分を破棄して再開する（Webの設定ダイアログと同じ方針）。
- 保存するのはアプリ自身の一時停止・省電力・背景の3設定だけ。壁紙ONは保存しない。旧ファイターズ表面の頻度・エフェクト量の保存キーは起動時に削除する。音・通知・API・アクセス解析・ログイン自動起動はない。
- **ファイターズはお蔵入り**（2026-11-16のユーザー指示）。手動・自動の対戦と呼びかけのUI・入力は存在せず、自動対戦はエンジン側でoffに固定される。戦闘のエンジンと回帰テストは内部検証用に残る。キーボード入力は一切取らない（グローバル監視もなし）。
- 壁紙は各ディスプレイのサイズから2倍以上の整数倍率を選び（Retinaでは backing scale と合成され、1ドットは整数個の物理ピクセルになる）、1ドットの大きさを揃える。16:9以外では1024×576pxのワイドマットから部屋の続きを出すので、左右の1px引き伸ばし帯が出ない。外部ディスプレイの2048×864では、書斎480×270を3倍、周囲をマットで表示する。マットより極端に広い／縦長の面では、外周を部屋の天井・床色でベタ塗りする。
- 待機中の演出は**静かな来客**のみ。綴星リュミエ・汐見のリツカ・紙灯のユメが1体ずつ遊びに来て、歩いて立ち止まり、会釈して帰る（戦闘なし）。初回75〜105秒、以降は2〜3分の待機を挟む。[仕様](<quiet-visitors.md>)。
- 背景は「夕凪」「月夜」「雨音」「朝凪」「雪あかり」の5種。プレビューのツールバーまたはメニューバーの「背景」から切り替え、選択は保存する。各背景は480×270px＋1024×576pxのワイドマットを持ち、整数倍描画は共通。「雨音」は雨の景色で、音は鳴らない。
- ディスプレイの追加・切断・配置変更では、新しいパネルを先に作ってから古いパネルを閉じる（build-then-swap）。元の壁紙が一瞬見えるちらつきを防ぎ、再構成中の一時的な失敗では既存パネルを維持して次の通知でやり直す。
- プレビューのツールバーは「タイトル（タグライン『おっとり。ときどき、ぼうっと。』）／背景／一時停止／壁紙／設定／作品について」。「設定」メニューは省電力のみ。シーン下のキャプションは生活観察／来客の共有行を表示し、停止理由はフッターが担当する。
- メニューバーに「メモリ使用量（プロセス）」を表示する。アプリ自身が持つ描画・素材は10MB前後で、残りはAppKit／JavaScriptCore／ウィンドウサーフェスの固定オーバーヘッド。プレビューを閉じたときはウィンドウとビューを解放する。

## ビルド

既存のNode/npm、Swift 6.2以上とmacOS SDKが必要。Swiftパッケージに外部依存はない。新しいブラウザーやnpm／Python／Swiftパッケージを自動導入しない。

スクリプトは依存なしのローカルパッケージなので、SwiftPMの入れ子サンドボックスが使えない制限環境でもビルドできるよう `--disable-sandbox` を付けて `swift test`／`swift build` を実行する。これは外部依存・プラグインを無効化する意味ではなく、このパッケージではもともと存在しない。

```sh
# 素材がなくてもビルドできる、初期仮素材版
npm run mac:test
npm run mac:build -- --placeholder

# 明示的に許可された個人用の生成素材版（公開不可）
npm run mac:test -- --local-preview
npm run mac:build -- --local-preview
```

ローカル生成素材の使用は `--local-preview` が必要。保存済みの素材台帳・SHA-256を確認してから、必要な画像・JSON・共有コア・クレジットだけを同梱する。参考画像・生成マスター・研究資料・開発用依存・個人パスは同梱しない。

出力はGit対象外の一意なビルドフォルダーに作り、既存のアプリを削除・上書きしない。アプリ・ZIP・SHA-256・同梱ファイル台帳を記録する。画面構成が変わったときは接続中のディスプレイを調べ直し、パネルを追加・削除する。ビルド時に壁紙をONにしたり、システム設定・自動起動・Gatekeeperの設定や隔離属性を変更したりしない。

## 署名と権利

個人用のローカル検証物で、Apple Developer ID署名・公証・一般配布は行わない。アドホック署名＋Hardened Runtimeを使用する。JavaScriptCoreが同梱・ハッシュ確認済みコードを動かすための `allow-jit` だけを付け、ライブラリー検証無効化・広いファイル操作ブリッジ・外部通信ブリッジは付けない。アプリがサンドボックス化されているという主張ではない。

今回の作成依頼は、個人用アプリの作成・ローカル検証への承認であり、第三者のキャラデザインや参照画像の公開・Mac配布許諾の確認ではない。既存の許諾未確認フラグを残し、公開・再配布を禁止したまま扱う。

生成された `.app` は、このMac上のローカルフォルダーで使用する。ダウンロードしたZIPから展開するとmacOSの警告が出る場合がある。アプリは未公証であり、こちらから保護設定の無効化や属性削除はしない。Apple Silicon向けのローカルビルドを前提にし、他のMac／OSバージョンでの動作保証はしない。

## 起動と停止

1. ZIPなら先に展開してアプリ全体を取り出す。アプリ内部の実行ファイルだけを移動しない。
2. アプリを開くとプレビューが出る。動きとサイズを確認する。
3. 使う場合だけ「壁紙にする」またはメニューバーの「壁紙を表示（全ディスプレイ）」を選ぶ。接続中の全ディスプレイに表示される。
4. OFFにすると元の壁紙が見える。プレビューを閉じてもメニューバーには残る。完全に止めるには「終了」。

## ファイターズ（お蔵入り）

2026-11-16のユーザー指示により、対戦・呼びかけのボタン・説明・設定を画面から撤去した。旧版（Build 16以前）を起動している場合は終了してから新しいアプリを開く。初回表示は静かな書斎のまま。

- 共有エンジンは生活リズムの進行に引き続き使うが、`frequency`は起動時に`off`へ固定され、自動対戦はスケジュールされない。来客は頻度と独立しており従来どおり訪れる。
- 戦闘のモジュール・コマンドライン検証（`--fighters-self-test`等）・Swift/Nodeの回帰テストは内部検証用に残置。これらはビルド時に実行されるが、アプリの画面には現れない。
- 過去の仕様・QA項目は[fighters-mvp](<fighters-mvp.md>)／[endless-boss-rush](<endless-boss-rush.md>)に履歴として残る。

## 検証の区別

- Nodeのテスト：共有世界・描画コマンド・安全なジオメトリ・Web互換性。
- Swift Testing：素材の整合性、JavaScriptCoreとの一致、60Hz更新、15/30/60fpsの30分再生、停止復帰・低電力・静止の方針、画像とアイコン、パス制限。
- コマンドライン自己検証：署名後の実行ファイルが同梱素材と共有コアだけで起動・描画する。背景5種と`--variant`の描画、メモリfootprintの読み取りも確認する。
- 起動スモーク（`--smoke-test`、ビルドスクリプトが自動実行）：プレビューとメニューバー・設定メニューが生成され、プレビューを閉じたときのウィンドウ／ビュー解放と、開き直しの生成を検証する。壁紙はONにしない。可視アニメーション・アイコン操作・Space・実機スリープの合格とは別。
- ネイティブPNG書き出しは、実際に使う描画器の出力であって、デスクトップ画面の録画／スクリーンショットではない。`--render-preview --width 2048 --height 864`、`--variant` で、ユーザーの横長画面・背景5種を確認できる。
- 書き出したPNG（`native-preview-wide.png`と各背景）は目視確認用で、実ウィンドウの可視・操作・クリック透過の合格とは別。戦闘系の書き出し（`native-room-event-wide.png`、`native-manual.png`、`native-boss.png`）はお蔵入り後も内部回帰用としてビルドが生成する。

### 手動で残る受け入れ確認

- [ ] 可視状態で5分以上、待機・まばたき・歩行・反転・睡眠・6種類の仕草・静かな来客と帰りを確認する。戦闘が一切始まらないこと。
- [ ] 720×470pt の最小ウィンドウでツールバーが欠けないこと。設定メニュー・About の顔表示とキャプション行を確認する。
- [ ] 壁紙ONで2048×864の左右がマットで自然につながり、整数倍のドットが揃って見えるか確認する。海面のきらめき・光の粒・ランプ・鳥がうるさくないかも見る。
- [ ] 背景5種（夕凪・月夜・雨音・朝凪・雪あかり）を切り替え、選択が再起動後も保存されること、月夜・雨音でもキャラクターが見やすいことを確認する。
- [ ] 「作品について」のクレジットが最後までスクロールでき、⌘Cでコピーできること。メニューを開いている間は風景が止まり、閉じると再開すること。メニューバー項目の状態表示（壁紙ON・一時停止）が実際の状態と一致すること。
- [ ] メニューバーのメモリ使用量表示と、プレビューを閉じた後の解放をActivity Monitorで確認する。
- [ ] 壁紙ON/OFFでアイコン・通常ウィンドウ・クリックが阻害されず、OFF／終了で元の壁紙が見える。
- [ ] Space／フルスクリーン／ディスプレイの追加・切断・配置変更が正常。全画面で同じ世界が同期し、クリック透過とアイコン下のレイヤーが保たれる。
- [ ] OS低電力・Reduce Motion・一時停止・実機スリープ復帰を確認。
- [ ] 実時間30分のCPU・メモリ・発熱を測定する。シミュレーション30分テストで代用しない。
- [ ] ダウンロード・別のMac・異なるOS・Gatekeeperでの扱いを確認。公証済み配布ではない。
