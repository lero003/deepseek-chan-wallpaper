# Mac版 — 個人用ローカル試作

## 方針

AppKit／CoreGraphics／JavaScriptCoreだけを使うMacホスト。Web版のTypeScriptの世界・アトラス・描画コマンドをIIFEへビルドし、その同じコードをJavaScriptCoreで実行する。別言語へ行動ロジックを複製しない。HTMLやブラウザーを常駐させず、Webサーバー・Node.js・ネット接続はアプリ実行に不要。

- 初回起動はプレビューのみ。壁紙ONはユーザー操作で選ぶ。壁紙ON状態は次の起動へ自動復元しない。
- 主画面のみ。デスクトップ背景より上・アイコンより下のクリック透過NSPanelを使う。
- 元の壁紙のURL取得・コピー・設定変更を行わない。OFF・終了・クラッシュ時にアプリ所有のウィンドウがなくなれば、元の壁紙がそのまま見える方式。
- メニューバーでプレビュー・壁紙ON/OFF・背景切替・一時停止・省電力・メモリ表示・クレジット・終了を操作する。
- 通常30fps、手動またはOS低電力時15fps。Reduce Motionでは静止。画面非表示／セッション非アクティブ／スリープで時計とタイマーを止め、復帰差分を破棄する。
- 保存するのはアプリ自身の一時停止・省電力・自動対戦の頻度・エフェクト量・背景の5設定だけ。ゲームの進行・押下キー・壁紙ONは保存しない。音・通知・API・アクセス解析・ログイン自動起動はない。
- 「テラスで3連戦」でプレビュー内だけを手動化。横スクロールのない固定アリーナで、雑魚戦2回と綴星リュミエとの1対1。開戦・休息・決着・帰宅で区切る。壁紙は常に非アクティブ・クリック透過で、手動ゲーム中は元の生活ループを表示する。グローバルキー監視は使わない。
- 壁紙は主画面のピクセル数から2倍以上の整数倍率を選び、1ドットの大きさを揃える。16:9以外では1024×576pxのワイドマットから部屋の続きを出すので、左右の1px引き伸ばし帯が出ない。外部ディスプレイの2048×864では、書斎480×270を3倍、周囲をマットで表示する。
- 壁紙の自動イベントは**テラスでの自動操縦の対戦**（ユーザー指示で小事件から変更）。開始から途中の戦いとして入り、増援が続いて30秒前後で書斎へ戻る。カメラ960固定・章題/HUD/ボスなし。手動の3連戦とボスはプレビュー内だけ。
- 背景は「夕凪」「月夜」「雨音」の3種。プレビューのツールバーまたはメニューバーの「背景」から切り替え、選択は保存する。各背景は480×270px＋1024×576pxのワイドマットを持ち、整数倍描画は共通。「雨音」は雨の景色で、音は鳴らない。
- プレビューのツールバーは「タイトル（タグライン『おっとり。ときどき、つよい。』）／背景／一時停止／壁紙／設定／作品について」。省電力・エフェクト・自動対戦の頻度は「設定」メニューにまとめ、既存の5保存設定のみを使う。書斎で休んでいる時は「呼んでみる」で小さく応答（20秒に1回・プレビュー限定・壁紙には文字も反応も出ない）。自動モードの下部ラベルは生活観察／呼びかけ／帰宅の共有キャプションを表示し、停止理由はフッターが担当する。
- メニューバーに「メモリ使用量（プロセス）」を表示する。アプリ自身が持つ描画・素材は10MB前後で、残りはAppKit／JavaScriptCore／ウィンドウサーフェスの固定オーバーヘッド。プレビューを閉じたときはウィンドウとビューを解放する。

## ビルド

既存のNode/npm、Swift 6.2以上とmacOS SDKが必要。Swiftパッケージに外部依存はない。新しいブラウザーやnpm／Python／Swiftパッケージを自動導入しない。

スクリプトは依存なしのローカルパッケージなので、SwiftPMの入れ子サンドボックスが使えない制限環境でもビルドできるよう `--disable-sandbox` を付けて `swift test`／`swift build` を実行する。これは外部依存・プラグインを無効化する意味ではなく、このパッケージではもともと存在しない。

```sh
# 素材がなくてもビルドできる、初期仮素材版
npm run mac:test
npm run mac:build -- --placeholder

# 明示的に許可された個人用の生成素材版（公開不可）
npm run mac:test -- --local-preview
npm run mac:build -- --local-preview
```

ローカル生成素材の使用は `--local-preview` が必要。保存済みの素材台帳・SHA-256を確認してから、必要な画像・JSON・共有コア・クレジットだけを同梱する。参考画像・生成マスター・研究資料・開発用依存・個人パスは同梱しない。

出力はGit対象外の一意なビルドフォルダーに作り、既存のアプリを削除・上書きしない。アプリ・ZIP・SHA-256・同梱ファイル台帳を記録する。ビルド時に壁紙をONにしたり、システム設定・自動起動・Gatekeeperの設定や隔離属性を変更したりしない。

## 署名と権利

個人用のローカル検証物で、Apple Developer ID署名・公証・一般配布は行わない。アドホック署名＋Hardened Runtimeを使用する。JavaScriptCoreが同梱・ハッシュ確認済みコードを動かすための `allow-jit` だけを付け、ライブラリー検証無効化・広いファイル操作ブリッジ・外部通信ブリッジは付けない。アプリがサンドボックス化されているという主張ではない。

今回の作成依頼は、個人用アプリの作成・ローカル検証への承認であり、第三者のキャラデザインや参照画像の公開・Mac配布許諾の確認ではない。既存の許諾未確認フラグを残し、公開・再配布を禁止したまま扱う。

生成された `.app` は、このMac上のローカルフォルダーで使用する。ダウンロードしたZIPから展開するとmacOSの警告が出る場合がある。アプリは未公証であり、こちらから保護設定の無効化や属性削除はしない。Apple Silicon向けのローカルビルドを前提にし、他のMac／OSバージョンでの動作保証はしない。

## 起動と停止

1. ZIPなら先に展開してアプリ全体を取り出す。アプリ内部の実行ファイルだけを移動しない。
2. アプリを開くとプレビューが出る。動きとサイズを確認する。
3. 使う場合だけ「壁紙にする」またはメニューバーの「壁紙を表示（主画面のみ）」を選ぶ。
4. OFFにすると元の壁紙が見える。プレビューを閉じてもメニューバーには残る。完全に止めるには「終了」。

## ファイターズの操作

旧版を起動している場合は終了してから新しいアプリを開く。初回表示は静かな書斎のまま。「対戦を見る」で壁紙と同じ自動対戦をすぐ確認できる。「テラスで3連戦」で手動を開始し、前面のプレビューにだけフォーカスを移す。敵を倒すと短い休息を経て次のラウンドへ進むため、徒歩での移動は不要。

- WASD／矢印で左右・奥行き移動、J/Zで3段コンボ、K/Xで回避、L/Cでゲージ100の必殺。
- Escでゲームをポーズ。既存のメニュー「一時停止」は風景全体の停止で別設定。OS Reduce Motionの静止中は遊ぶ操作を無効にする。
- 「書斎へ戻る」で入力解除・HUD消灯・帰還（壁紙ON/OFFとは別操作）。敗北・TIME UPは「このラウンドを再挑戦」、勝利後は「もう一戦」で最初から。結果のSCORE/RANKと所要時間は新戦ごとにリセットし、ポーズ／フォーカス喪失中は時間に含めない。失敗ラウンドの得点はクリア済みチェックポイントまで巻き戻す。
- 別ウィンドウ・スリープへ移ると入力を解除。手動の戦闘はフォーカス中だけ進み、壁紙側の生活は既存の可視性方針に従う。戻ると1秒の攻撃猶予。
- 自動対戦の頻度／エフェクト量はメニューバーから。音は常時無音。各ラウンド90秒・SCORE・RANK・CONTINUEは手動プレビュー内だけの表示。主人公の承認済み16コマは不変。ボスの制作案8姿勢は明示的なローカルプレビューにだけ同梱し、素材なし／画像読込失敗は独自の仮描画へ戻す。主人公の専用戦闘コマ、雑魚・戦闘背景の完成素材と可視操作感は未受け入れ。

## 検証の区別

- Nodeのテスト：共有世界・描画コマンド・安全なジオメトリ・Web互換性。
- Swift Testing：素材の整合性、JavaScriptCoreとの一致、60Hz更新、15/30/60fpsの30分再生、停止復帰・低電力・静止の方針、画像とアイコン、パス制限。
- コマンドライン自己検証：署名後の実行ファイルが同梱素材と共有コアだけで起動・描画する。背景3種と`--variant`の描画、メモリfootprintの読み取りも確認する。
- 起動スモーク：プレビューとメニューバーが生成される。壁紙はONにしない。可視アニメーション・アイコン操作・Space・実機スリープの合格とは別。
- ネイティブPNG書き出しは、実際に使う描画器の出力であって、デスクトップ画面の録画／スクリーンショットではない。`--render-preview --width 2048 --height 864`、`--render-room-event`、`--variant` で、ユーザーの横長画面・書斎内事件・背景3種を確認できる。
- 書き出したPNG（`native-preview-wide.png`、`native-room-event-wide.png`、`native-manual.png`、`native-boss.png`）は目視確認用で、実ウィンドウの可視・操作・クリック透過の合格とは別。

### 手動で残る受け入れ確認

- [ ] 可視状態で5分以上、待機・まばたき・歩行・反転・睡眠・自動対戦と帰還を確認する。
- [ ] 「呼んでみる」の応答（約1.2秒の正面ポーズ＋約3秒の台詞）が小さく自然で、睡眠・対戦を邪魔しないこと。無効理由（お昼寝／お散歩／少し待ってね 等）が分かること。720×470pt の最小ウィンドウでツールバーが欠けないこと。設定メニュー・About の顔表示を確認する。
- [ ] 壁紙ONで2048×864の左右がマットで自然につながり、整数倍のドットが揃って見えるか確認する。海面のきらめき・光の粒・ランプ・鳥がうるさくないかも見る。
- [ ] 背景3種（夕凪・月夜・雨音）を切り替え、選択が再起動後も保存されること、月夜・雨音でもキャラクターが見やすいことを確認する。
- [ ] メニューバーのメモリ使用量表示と、プレビューを閉じた後の解放をActivity Monitorで確認する。
- [ ] 手動の移動・3段攻撃・回避・必殺・敗北／再挑戦・ポーズ。押下中のアプリ切替、Command等を押しながらキーを離す操作で入力が残らない。
- [ ] 壁紙ON/OFFでアイコン・通常ウィンドウ・クリックが阻害されず、OFF／終了で元の壁紙が見える。
- [ ] Space／フルスクリーン／主画面の変更／ディスプレイ再接続が正常。
- [ ] OS低電力・Reduce Motion・一時停止・実機スリープ復帰を確認。
- [ ] 実時間30分のCPU・メモリ・発熱を測定する。シミュレーション30分テストで代用しない。
- [ ] ダウンロード・別のMac・異なるOS・Gatekeeperでの扱いを確認。公証済み配布ではない。
