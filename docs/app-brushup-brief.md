# アプリ・ブラッシュアップ指示書 — おっとり。ときどき、つよい。

作成: 2026-11-12 / 対象: くじらの散歩道の個人用Mac版＋Webプレビュー

**状態: B01〜B05 実装済み（2026-11-12）。A01（追加4ポーズ）は画像生成が環境上不可のためスルー。実装内容・検証・未受け入れは [current_status](<current_status.md>) が正。以下は当初の作業仕様（記録）。公開・push・素材権利確認は引き続き未了。**

## 1. 結論

目指すのは「機能の多い壁紙」ではなく、**作業机に、小さな同居人がいるアプリ**。

- メインコピー: **「おっとり。ときどき、つよい。」**
- 説明: 「海辺の書斎で、DeepSeekちゃんと過ごす。普段はのんびり、ときどきテラスでひと勝負。」
- 名前は「くじらの散歩道」を維持。説明の近くに「DeepSeekちゃんのいる、小さな書斎」。公式製品・公式設定とは表現しない。
- 可愛さの軸: **眠そうな落ち着き／呼びかけに小さく応える／戦った後は何事もなかったように日常へ戻る**。
- キャッチーさは大きな演出でなく、この三つが一目で伝わること。育成・ログイン報酬・通知・親密度で会いに来させない。

**推奨着手順は B01 → B02 → B03 → B04。B05はその後。追加アートA01は別スコープ。** 最初から全部を盛らず、「背景がすぐ選べる・主役が分かる・ひとつ反応がある」を最小完成形にする。

## 2. 現状に対する診断

確認根拠は現行ソースと既存の描画QA。実行中アプリを操作した評価ではない。

| ヒレ耳、半目、尾、メイド服の識別性。生活16コマと戦闘8キー姿勢 | 描き直しより「この子に会う」入口と顔が読める配置 |
| まばたき・歩行・睡眠・窓辺への移動・背景別リズム・睡眠の泡 | これらを新機能として再提案しない。まとまりのある短い反応を一つ足す |

## 3. 変えない境界

実装上の正本は[プロジェクト方針](<../AGENTS.md>)・[アート方針](<art-direction.md>)・[Fighters仕様](<fighters-mvp.md>)。この提案で上書きしない。

- 承認済み生活16コマ・3背景・各マットはbyte不変。新規差分が必要なら別シート。ヒレ耳・半目・髪飾り・尾・衣装・頭身を変えない。
- 壁紙は無入力・無HUD・文字なし。整数倍率2倍以上、固定カメラ、自動対戦は途中から開始・増援あり・約30秒・ボスなし。旧書斎の小事件へ戻さない。
- 手動は固定テラス1舞台・敵2種・ボス1体。90秒・得点・CONTINUE・raw runStatsの境界を維持。今回、難易度や戦闘バランスを調整しない。
- AppKit／CoreGraphics／JavaScriptCore＋共有TypeScript／Canvas 2D。React・SwiftUI・新UIライブラリー等への置き換えなし。外部フォント・第三者ランタイム・音・LLM/API・分析・通知を追加しない。
- 初回はプレビュー。壁紙ONは明示操作のみ、元のシステム壁紙設定・ログイン項目を変えない。既存のMac保存設定5項目以外は追加保存しない。Webに新たな永続化を持ち込まない。
- 生成素材はGit対象外、ローカル専用・許諾pending。placeholderでprivate素材をimportしない。公開・push・リリース更新は別の明示依頼が必要。
- Reduce Motion・一時停止・非表示・スリープ時の停止を新しい演出より優先。独立した常時タイマーを増やさない。

## 4. 体験・見た目の完成イメージ

### 開いてから10秒で分かること

1. 最初に見えるのは書斎と本人。説明ダイアログや自動対戦を強制しない。
2. 周辺に小さく「くじらの散歩道」「おっとり。ときどき、つよい。」。
3. 夕凪／月夜／雨音を選べる。Macでは「壁紙にする」が主操作。
4. 気になったら「呼んでみる」。遊びたい人だけ「テラスで3連戦」から既存の手動対戦へ。

```text
くじらの散歩道                           [設定] [作品について]
DeepSeekちゃんのいる、小さな書斎

                  書斎とdeepseekちゃん
            （顔・髪飾り・尾にUIを重ねない）

夕凪 / 月夜 / 雨音          [呼んでみる] [壁紙にする ※Macのみ]
おっとり。ときどき、つよい。   対戦を見る / テラスで3連戦
```

このワイヤーは階層の説明。横幅不足時に全要素を一列へ押し込まない。WebにMac壁紙ボタンを作らない。

### 見た目の数値指針

- 主役は既存ドット絵。背景を薄くする、キャラだけ発光させる、常時拡大縮小する等で目立たせない。
- アプリの周辺は既存の紺のインク色＋淡い紙色を継承。例: 背景 `#1a2030`、面 `#262b3b`、文字 `#ece5d8`、補助 `#c4c0ca`、操作のアクセント `#b9d4d8`。最終色は実測コントラストで決める。既存アートの青紫色は変更しない。
- 文字は既存OSフォント。本文・操作13〜14px/pt、補助11〜12、見出し18〜20。9pxの英文や装飾番号を主たる情報にしない。
- Webの操作領域は原則44×44 CSS px以上。Macは標準コントロールと十分な間隔を優先。角丸は6〜8px程度、余白8/12/16/24の系列。大きなカードを並べない。
- 設定表示の遷移は120〜180msのopacity中心。ドット絵のキャラにCSSの弾性拡大・ぼかし・小数ズームを使わない。Reduce Motionでは遷移なし。
- 主要文字4.5:1以上、フォーカス／操作境界3:1以上を確認。選択は色だけでなくチェックやラベルでも示す。

## 5. 実装タスク

### B01 / P0 — 言葉と背景選択を正しく揃える

**狙い:** 「この子のアプリ」と一目で分かり、触った瞬間に迷わない。新アート・新シミュレーションなし。

**指示**

1. 上記コピーを控えめに配置。「事件を見る」は「対戦を見る」に統一。押すと既存 `demo`、手動は既存 `play` のまま。ゲーム帰宅の「壁紙へ戻る」は「書斎へ戻る」へ変更し、Macの壁紙ON/OFFと区別する。実際の壁紙機能のラベルまで一括置換しない。
2. 背景候補は必ず標準0を先頭に入れ、実際に読めた追加背景だけを追加。初期選択とrendererの表示を一致させる。欠落素材を選択可能にしない。
3. 「雨音」は背景名として残し、「雨の景色・音は鳴りません」と説明。背景別の生活リズムを説明し、AIが感情を判断するような表現はしない。
4. 短い台詞は本作の創作テキストとして扱い、公式台詞とは呼ばない。システム状態・権利説明は装飾的な台詞に置換しない。
5. 静的HTML、初期化後の文言、Macメニュー、About、READMEを照合。制作版／placeholderの素材説明を分ける。

**主な接点:** [HTML](<../index.html>)、[Web初期化](<../src/app-web/main.ts>)、[FightersUI](<../src/app-web/fighters-ui.ts>)、[Mac操作](<../src/app-mac/App/AppController.swift>)、[Mac対戦バー](<../src/app-mac/App/FightersControls.swift>)。

**受入:** 夕凪→月夜→雨音→夕凪が選択可能／候補・表示・読み上げ名が一致／variant一部欠落とplaceholderでも標準へ戻れる／戦闘の開始経路・背景の保存仕様・既存クレジットは不変。

### B02 / P0 — 「眺める・選ぶ・遊ぶ」の階層を作る

**狙い:** 設定の説明を読む前に、好きな景色で過ごせる。

**指示**

1. Webは背景選択をAboutから常設操作へ移動。DOMの同一idを複製しない。3候補なら小さな選択列、狭幅ではlabel付きselectへ。候補が標準のみなら「夕凪」と表示し、空の選択UIを出さない。
2. 「設定」は停止／省電力／自動対戦頻度／エフェクト等の既存操作、「作品について」は説明とクレジットに分ける。MacはAppKitの標準パネル／popover等で構築し、既存メニューバー操作を残す。
3. 普段の最も強いCTAはMacの「壁紙にする」。表示中は「壁紙をやめる」と実状態を明示。「対戦を見る」「テラスで3連戦」は二次操作。手動モードだけ既存の戦闘操作を出す。
4. 設定を開いたときの停止・キー解放・閉じた後のフォーカス復帰を維持。新パネルを既存 `dialogOpen`／`modalOpen` 等の停止条件へ漏れなく接続。
5. Macのメニュー冒頭は状態と「プレビューを開く」を優先。既存メモリ計測表示は診断側へ下げてもよいが、計測・停止仕様を勝手に削らない。
6. 装飾で権利注意を消さない。常設は「非公式・個人用プレビュー」、詳細へ1操作。長文を全て見せることでシーンを圧迫しない。
7. 無効な操作の近くに「静止画で眺めるがON」「OSの視差効果を減らすに合わせて静止中」「一時停止中—再開」等、実際の理由と既存の解除導線を表示。停止理由は複数候補から一つに整理し、フォーカスを勝手に奪わない。Macの壁紙ON/OFFは成功後の実状態を示し、停止中＝壁紙OFFと誤認させない。

**主な接点:** [Webスタイル](<../src/app-web/style.css>)、B01のホストUI、[Web再生方針](<../src/app-web/playback.ts>)、[Mac再生方針](<../src/app-mac/Core/PlaybackPolicy.swift>)。再生方針自体の弱体化は禁止。

**受入:** Web幅360/768/1440px・200%拡大、Mac最小720×470ptと既定1000×680ptで操作が欠けない／選択から背景変更まで1操作／TabとVoiceOverで操作可能／ダイアログを閉じると起点へフォーカス復帰／通常表示に戦闘HUDなし／壁紙を勝手にONにしない。

### B03 / P1 — プレビュー限定「呼んでみる」

**狙い:** 可愛さを「見た目」から「小さな応答」へ。撫でる・追い回す・育成にせず、ひとつだけ分かりやすい接点を作る。

**指示**

- アプリのシーン外に「呼んでみる」ボタン。任意操作のみ。キャラをクリックする隠し操作や、グローバルマウス監視は実装しない。
- 初版は既存16コマの再利用。元のturn/idleを原寸で確認して、正面寄りのフレームを一瞬見せ、「ん、呼んだ？」をシーン外の小さな状態欄に出す。**手振り・笑顔の新ポーズを既存コマで実現したとは呼ばない**。
- キャラの足元・現在位置・縮尺は固定。反応は最大1.2秒、文章は同一欄で約3秒。台詞はタイプライター表示にせず即時表示。1回の操作で1回だけ。
- 受付は `auto + rest + idle` かつプレビューが可視・操作可能な時だけ。他は無効にし、「いまはお散歩中」「いまはお昼寝中」「対戦が終わったら呼べます」等をボタン近くに説明。反応を待ち行列に積まない。
- クールダウン20秒（稼働tick基準）。カウントダウンUIなし。連打で反応延長・粒子増加・状態変化を起こさない。睡眠中の強制起床なし。
- **実世界を変えないpreview専用の描画上書き**として実装。元のWorld／乱数／移動／睡眠時刻／対戦予定を変更しない。反応中にidleから離れたら終了。描画時に状態を更新しない。
- 共通TSに有限の `CompanionCue` と純粋な表示解決関数を設け、既存60Hz更新から経過させる。ホストは受付条件・表示・読み上げのみ担当。初版でWorldのBehaviorや16コマのatlasスキーマを増やさない。
- 壁紙presentationはcueを無視。Macでプレビューと壁紙が同時に存在しても、壁紙の描画・挙動は呼びかけ前後で不変。プレビュー閉鎖／フォーカス喪失／停止／背景切替／対戦開始でcueを破棄する。
- Reduce Motion・ユーザー静止・停止中は反応ボタンを無効化し原因を明示。停止解除を反応の副作用にしない。新規UserDefaults/localStorageなし。

**主な接点:** 新設候補 `src/companion/cue.ts`、[game固定更新](<../src/fighters/game.ts>)、[描画plan](<../src/fighters/render-plan.ts>)、[atlas](<../src/render/atlas.ts>)、[native bridge](<../src/app-mac/native-bridge.ts>)、[Macモデル](<../src/app-mac/Core/Models.swift>)、Web/Mac操作UI。新設パスは提案であり、既存モジュール構造に合わせて確定する。

**受入:** 同じseed・入力・tickでWeb/JSCが同じcue／壁紙planはcue有無で完全一致／クリック100回でも1反応のみ／sleepや戦闘へ割り込まない／停止・不可視復帰で古い台詞や反応が再生されない／placeholderで範囲外フレームを参照しない／失敗時は元のidleへ戻る／既存対戦スケジュール・得点・world乱数系列は不変。

### B04 / P1 — 「強いのに、帰るとおっとり」の余韻

**狙い:** 戦闘量を増やさず、キャラのギャップを記憶に残す。

**初版の指示**

1. 自動対戦の途中開始・増援・時間・帰宅は変更しない。手動戦闘の数値や既存READY/FIGHT/結果も変更しない。
2. 帰宅が実際に完了したときだけ、プレビューのシーン外状態欄へ「ふう。書斎がいちばん。」を一度、約3秒。手動の途中帰宅には「ひと休みしよう。」。勝っていないのに勝利台詞を出さない。
3. 判定は観測されたフェーズ遷移に基づき、render呼び出しごとに再発火させない。途中帰宅・初回rest・復帰時を区別。壁紙には台詞・バナー・HUDを一切追加しない。
4. B03と状態欄を共用し、優先順位は「実際のエラー／停止理由 > 対戦・帰宅の説明 > 呼びかけ返答 > 通常コピー」。文言の上書き競合をなくす。
5. 敗北表示は「今回はここまで。もう一度？」等、責めない文体へ整える。ただし「TIME UP」「このラウンドを再挑戦」と得点巻き戻しの説明を失わせない。
6. 日常時は常時の3連戦勧誘文に代え、実状態に対応する観察文を使う。「少しだけ、うとうと。」「海辺の書斎を、ひと歩き。」等を共通TSの純関数で選ぶ。短いturnは個別文章にせずidle相当にまとめ、候補が3秒安定してから差し替える。キャプション自体は非liveにし、生活遷移を毎回読み上げない。現在のgazeはidle移行後に判別情報が消えるため、idleというだけで「窓を見ている」と断定しない。ユーザーの在席・感情・実時間は推測しない。

**主な接点:** [directorの遷移](<../src/fighters/director.ts>)を参照し、主な変更は[Web表示](<../src/app-web/fighters-ui.ts>)と[Mac表示](<../src/app-mac/App/FightersControls.swift>)、B03の表示状態。戦闘ロジックを表示文言の都合で書き換えない。

**受入:** 自動／手動クリア／敗北／TIME UP／途中帰宅を区別／初回起動や復帰で「帰った」と誤表示しない／一時文言でシーン寸法が変わらない／壁紙にtextコマンドなし／現在の自動対戦時間とアーケードの回帰テスト維持。

### B05 / P2 — ローカルの「アプリの顔」を揃える

**狙い:** ウィンドウ・About・Dockで、汎用のクジラ印だけでなく「この子のアプリ」と分かる。

**指示**

- まずAboutに既存の承認済み正面寄りフレームを小さく配置。元画像を改変せず、nearestで整数倍表示。既存の非公式・帰属説明と並べる。
- Dockアイコンは別途実装スコープに含めると指示された場合だけ。既存顔まわりのトリミング案を16/32/64/128px相当で比較し、ヒレ耳・髪飾りが読めない小サイズに無理に全身を入れない。
- 制作版の派生アイコンはignoredなローカル生成物として扱い、出典・SHA・pendingを保持。元スプライトは変更しない。placeholderでは現在の自作クジラ印を維持。
- メニューバーは読みやすい既存「くじら」表示を基本にする。小さなカラー顔で可読性を落とさず、点滅・常時アニメーションをしない。

**主な接点:** [Mac About](<../src/app-mac/App/AppController.swift>)、[Web About](<../index.html>)、アイコンを含む場合のみ[Mac準備](<../scripts/prepare-macos.mjs>)・[Macビルド](<../scripts/build-macos.mjs>)を先に読む。

**受入:** 元アートhash不変／非公式・権利表示維持／欠落画像で空白や起動失敗にならない／placeholderの配布物にprivate由来アイコンが混入しない／新しい実行時依存なし。

## 6. さらに可愛くする追加アート案 A01（別スコープ）

コードだけでは「口元がゆるむ」「ヒレ耳が少し下がる」「照れる」は自然に表現しきれない。**本当に表情を増やすなら、全体リデザインではなく生活リアクション専用の別シート**が最も効く。

提案するキー姿勢は4種類まで。既存16コマへの追記・上書きは禁止。

| 姿勢 | キャラらしさ | 使う場面 |
| --- | --- | --- |
| 気づく | 半目のまま、視線だけ少しこちらへ。ヒレ耳は低く、立てない | B03の呼びかけ |

**制作仕様案:** 80×112セル、足元40/108、既存に合わせた共有80色・二値alpha・nearest。承認済み基準絵と生活シートを参照する。ヒレ耳・半目・衣装・尾・髪飾りの同一性を原寸と3倍で確認。加工済みのキー姿勢を連続アニメーションと偽らない。必要な中割りは別途見積もる。

**組み込み:** 既存16コマのparserを緩めず、別のoptional atlasとして検証。pose単位の欠落・破損・不正寸法にフォールバック。B03は従来turn/idleへ、あくびは通常sleepへ戻る。新規キー姿勢の表示は各0.6〜1.8秒を初期値に接地と戻りを調整し、生活演出は自然な遷移時だけ、頻繁に呼び出さない。

**進行:** 追加素材の制作・統合を依頼された後、4ポーズの比較→制作側レビュー→加工・台帳→両レンダラー統合→QA。既存素材を再生成しない。衣装替え・大きな目・猫耳化・別頭身・新キャラ・新背景・新音声へ拡大しない。
