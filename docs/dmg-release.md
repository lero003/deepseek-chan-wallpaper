# リリースDMG（非公開リポジトリ）の配布と試用

## これは何か

「くじらの散歩道」の**個人検証用リリース**。非公開のGitHubリポジトリ内の**個人テスト用リリース（Published／Prerelease）**で、一般公開・一般配布ではない。リポジトリへのアクセス権があるアカウント（本人）だけが見られる。目的は本人の別Macでの個人利用のみ。

最新は **ゆっくり対戦 Build 19**（2026-11-17、パッケージタグ `sparring-build19-dmg`、ソースタグ `sparring-build19`）。

- 対象: Apple Silicon（arm64）、macOS 14以降
- 署名: アドホック署名のみ。Appleの公証なし
- 初回起動はプレビューのみ。壁紙は明示操作でON
- 元の壁紙設定・ログイン自動起動は変更しない
- 音・通信・解析・自動アップデートはない
- 素材の権利・公開許諾は未確認。**再配布・公開アップロードをしない**

## タグ・ReleaseはBuild19の1本だけ

2026-11-17のユーザー依頼で、古いタグ・Release（Build6〜15系・ドラフト計9本）を全削除し、`sparring-build19` / `sparring-build19-dmg` とこのReleaseだけを残したクリーン状態にした。過去の作業コミットは`main`の履歴に残っており、必要ならコミットSHAからいつでも復活できる。以後も**リリースは常に差し替えではなく新ビルド1本**を基本とし、増えすぎたら同じように整理する。

## 他のMacで試す手順

1. 非公開リポジトリの [Releases](https://github.com/lero003/deepseek-chan-wallpaper/releases) を、アクセス権のあるアカウントで開く（リポジトリ権限が必要）。
2. リリース「ゆっくり対戦 Build 19（個人テスト用）」から `KujiraWallpaper-Sparring-B19-arm64.dmg` と `SHA256SUMS.txt` を取得する。
3. `SHA256SUMS.txt` で整合を確認する。

   ```sh
   shasum -a 256 -c SHA256SUMS.txt
   ```

4. DMGを開き、「くじらの散歩道.app」を Applications へドラッグする（任意）。
5. アプリを**右クリック →「開く」**で起動する。未公証のため、ダブルクリックだけで警告が出る場合がある。macOS全体の保護を無効化しない。個別許可は「システム設定 > プライバシーとセキュリティ」から行う。
6. プレビューで動作を確認し、必要なら「壁紙にする」。終了はメニューバーから。

ZIP版（`KujiraWallpaper-Sparring-B19-arm64-local-preview.zip`）でも同じアプリを展開できる。DMGの方がApplicationsへの導入が簡単。

## 試してほしい項目

- [ ] 起動してプレビューが出る（初回に壁紙が勝手に出ない）
- [ ] 「書斎で過ごす」: 6種類の仕草（小さなジャンプ・くすくす笑い・小さなダンス・照れ覗きと手振り・のび・尾との戯れ）が穏やかに出て、来客のリツカ／ユメが歩く・会釈する
- [ ] 「リュミエとゆっくり対戦」: 固定テラスでリュミエと打ち合い・離脱・再接近を穏やかに繰り返す。HP/HUD/スコア/勝敗がなく、誰も倒れない
- [ ] シーン下の「背景」で夕凪・月夜・雨音・朝凪・雪あかりを切り替えられる（「雨音」は音が鳴らない）
- [ ] 壁紙OFFのときだけ「テラスで3連戦」の手動操作（歩く・3段コンボ・回避・必殺・ポーズ、90秒・SCORE・RANK）が効く
- [ ] 壁紙ONで手動対戦が終わし、選んでいた書斎／ゆっくり対戦へ戻る。壁紙はクリック透過で元の壁紙が戻る
- [ ] 接続中の全ディスプレイで同じ世界が整数倍で描かれ、追加・切断・配置変更にも追従する
- [ ] Space／フルスクリーン／スリープ復帰、終了後にプロセスが残らない
- [ ] 30分程度のCPU・メモリ・発熱（実時間）

## 既知の制限

- Intel Mac、macOS 13以前、公証済み配布、自動更新、音声には対応していない。
- 未公証のため、初回は右クリック→「開く」。Gatekeeperの挙動は環境により異なる。
- 承認済みの生活16コマ・背景5種・各マットは不変。追加生活24コマ・来客・生成ライバル/リュミエ画像もローカル専用で、権利・許諾は未確認（pending）。
- 実機の可視操作・壁紙ON/OFF・スリープ・実時間30分負荷・複数画面の実表示は、作成環境では未確認。テスト結果を共有してほしい。
- アプリ内の素材は個人用の生成素材。権利・許諾を確認していないため、公開・再配布・ストア提出をしない。
