# リリースDMG（非公開リポジトリ）の配布と試用

## これは何か

「くじらの散歩道」の**個人検証用リリース**。非公開のGitHubリポジトリ内の**個人テスト用リリース（Published／Prerelease）**で、一般公開・一般配布ではない。リポジトリへのアクセス権があるアカウントだけが見られる。

最新は **全ディスプレイ同期 Build 15**（2026-11-13、パッケージタグ `multi-display-build15-dmg`）。

- 対象: Apple Silicon（arm64）、macOS 14以降
- 署名: アドホック署名のみ。Appleの公証なし
- 初回起動はプレビューのみ。壁紙は明示操作でON
- 元の壁紙設定・ログイン自動起動は変更しない
- 音・通信・解析・自動アップデートはない
- 素材の権利・公開許諾は未確認。**再配布・公開アップロードをしない**

## 他のMacで試す手順

1. 非公開リポジトリの [Releases](https://github.com/lero003/deepseek-chan-wallpaper/releases) を、アクセス権のあるアカウントで開く（リポジトリ権限が必要）。
2. リリース「全ディスプレイ同期 Build 15（個人テスト用）」から `KujiraWallpaper-MultiDisplay-B15-arm64.dmg` と `SHA256SUMS.txt` を取得する。
3. `SHA256SUMS.txt` で整合を確認する。

   ```sh
   shasum -a 256 -c SHA256SUMS.txt
   ```

4. DMGを開き、「くじらの散歩道.app」を Applications へドラッグする（任意）。
5. アプリを**右クリック →「開く」**で起動する。未公証のため、ダブルクリックだけで警告が出る場合がある。macOS全体の保護を無効化しない。個別許可は「システム設定 > プライバシーとセキュリティ」から行う。
6. プレビューで動作を確認し、必要なら「壁紙にする」。終了はメニューバーから。

ZIP版（`KujiraWallpaper-MultiDisplay-B15-arm64-local-preview.zip`）でも同じアプリを展開できる。DMGの方がApplicationsへの導入が簡単。

## 試してほしい項目

- [ ] 起動してプレビューが出る（初回に壁紙が勝手に出ない）
- [ ] 接続中の全ディスプレイで同じ書斎が表示され、各画面の解像度に合った整数倍で描かれる。ディスプレイの追加・切断・配置変更後も追従し、クリックが透過する
- [ ] 書斎で数分待ち、6種類の仕草（小さなジャンプ・くすくす笑い・小さなダンス・照れ覗きと手振り・のび・尾との戯れ）が穏やかに出る。直前と同じ仕草が連続せず、歩行・睡眠・戦闘を中断しない
- [ ] シーン下の「背景」で夕凪・月夜・雨音・朝凪・雪あかりを切り替えられる（「雨音」は音が鳴らない）
- [ ] 来客のリツカ／ユメがローカル画像で歩き、会釈し、待機中も小さく動く
- [ ] 「呼んでみる」で、休んでいる時に小さく応える。お散歩中・お昼寝中は理由が出る
- [ ] 「対戦を見る」でテラス自動対戦が途中から始まり、約30秒で書斎へ戻る
- [ ] 「テラスで3連戦」で歩く・3段コンボ・回避・必殺・ポーズ、90秒・SCORE・RANK
- [ ] 敗北／TIME UPの再挑戦、書斎へ戻る、もう一戦
- [ ] 16:9以外のウィンドウ／画面でも、戦闘背景の外周が単色フレームで、引き伸ばしスジが出ない
- [ ] 壁紙ON/OFF、クリック透過、元の壁紙が戻る
- [ ] Space／フルスクリーン／スリープ復帰
- [ ] 終了後にプロセスが残らない
- [ ] 30分程度のCPU・メモリ・発熱（実時間）

## 既知の制限

- Intel Mac、macOS 13以前、公証済み配布、自動更新、音声には対応していない。
- 未公証のため、初回は右クリック→「開く」。Gatekeeperの挙動は環境により異なる。
- 承認済みの生活16コマ・背景5種・各マットは不変。Build14の追加生活24コマと生成ライバル画像もローカル専用で、権利・許諾は未確認（pending）。Build15の複数ディスプレイ同期は、この作成環境で物理的に2台以上を接続した可視確認をしていない。
- 実機の可視操作・壁紙ON/OFF・スリープ・実時間30分負荷は、作成環境では未確認。テスト結果を共有してほしい。
- アプリ内の素材は個人用の生成素材。権利・許諾を確認していないため、公開・再配布・ストア提出をしない。
