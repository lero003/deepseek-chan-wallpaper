# 全ディスプレイ同期 Build15 — 非公開プレリリース

ソースタグ: `multi-display-build15`。パッケージタグ: `multi-display-build15-dmg`。既存のBuild14以前のタグ・Releaseは変更しません。コードのバージョンは非公開試作の0.1.0、Mac bundle buildは15です。この更新は一般公開・画像の再配布許諾ではありません。

## 変更点

- Macの壁紙を、メインディスプレイだけでなく**接続中のすべてのディスプレイ**へ同期表示します。各ディスプレイに同じ世界を描くクリック透過パネルを1枚ずつ置きます。
- 各画面の解像度に合わせて、従来どおり整数倍率・ワイドマットで描画します。パネルはデスクトップアイコンより下、デスクトップ背景より上に置き、クリックは透過します。
- ディスプレイの追加・切断・配置変更を検知してパネルを張り直します。ミラーリングで同じ座標になる画面は重複ウィンドウを作りません。
- メニュー／ツールバーの表示を「壁紙を表示（全ディスプレイ）」「壁紙をOFF（全ディスプレイ）」に変更しました。
- Build 14の6種類の生活仕草（専用24コマ）、承認済み生活16コマ、背景5種、来客、戦闘、広い壁紙を引き継ぎます。
- 元の壁紙設定・ログイン自動起動・システム設定は変更しません。壁紙ON/OFFは明示操作だけです。

## 検証

- `npm run check`: 型検査、Node 257テスト、既定5素材の再現確認が成功。
- `npm run mac:test`と`npm run mac:test -- --local-preview`: Swift **各43テスト・9 suites**成功。新しい4テストで、横並び・負座標・ミラー重複・空/非有限フレーム・切断/再配置を検査。
- Build15アプリ: CFBundleVersion15、アドホック署名、起動スモーク、ZIP展開後の自己テスト2種が成功。
- DMG: 読取専用マウント、署名検証、イメージ内・コピー後の自己テスト2種、元ZIPとのbyte一致が成功。
- リリース登録後に再ダウンロードし、`SHA256SUMS.txt`とのSHA-256一致、DMG/ZIP双方の署名・自己テストを確認済み。
- 未確認: 実機で複数ディスプレイを接続した見た目、Space／フルスクリーン、ホットプラグ、異なる解像度・配置、クリック透過、30分の負荷、別Mac／OS、Gatekeeperの挙動。この環境で確認できた物理画面は1台のため、複数画面の実表示は自動テストで代替できていません。

## 使い方

1. DMGを開き、「くじらの散歩道.app」をApplicationsへドラッグします（任意）。
2. 起動するとプレビューが開きます。壁紙は「壁紙にする」を選んだときだけ表示されます。
3. 接続中の全ディスプレイに同じ書斎が表示されます。画面を追加・切断・配置変更した場合は自動で張り直します。
4. OFF・終了でアプリのウィンドウが消え、元の壁紙が見えます。音・通信・解析・ログイン自動起動はありません。
