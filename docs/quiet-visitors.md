# 通常待機中の静かな来客

2026-11-12の追加依頼「通常の待機時間にも定期的にボスキャラが訪ねてきてウロウロ」への実装。WebプレビューとMac壁紙に共通。
2026-11-13の追加依頼「動きが全然ないから不自然」「キャラの作り込みが微妙なのいる」への改修を含む。

## 来客の進行

- auto/restの有効な待機時間だけを数え、初回75〜105秒、退室後120〜180秒で訪問。非表示・一時停止・Reduce Motion・スリープの既存停止を維持し、復帰時に時間を取り戻さない。
- 綴星リュミエ／汐見のリツカ／紙灯のユメの3人。別seed乱数のバッグで一巡し、同じ人が連続しない。一度に1人だけ、左右から入り、書斎の手前で歩く・立ち止まる。45〜60秒経過で退室を始め、最長100秒。
- 歩きは30px/秒。歩幅は「歩いた距離」を`stride=22px`で割った位相で決め、停止・再歩行しても足の位相が飛ばない。最初の停止では向き直って小さく会釈し、以降の停止は「見る」「もじもじする」を交互に使う。退室は近い側の端へ向かう。
- 戦闘・homeへの切替で直ちに解除。敵/弾/HP/得点/戦績/アーケード時計を作らず、生活・戦闘の乱数や対戦予定を消費しない。自動対戦頻度offは来客を止めない。
- 既存リュミエの任意アートとコード描画の2人を再利用。承認済み画像は不変更。HUD/戦闘背景なし。書斎外キャプションに訪問者名を表示。
- ホストAPI `command(game, 'visitors', false)`で抑制可。DSHはこれを指定し、待機室へ来客を持ち込まない。新しい個人設定は保存しない。

## 動きと描き分け（2026-11-13）

- 承認済みの16コマ・背景・リュミエの8姿勢シートはbyte不変。新しい個人設定・依存・音・通信は追加していない。
- 同日の追加依頼で、汐見のリツカと紙灯のユメにもGPT Imageの8姿勢シートをローカル生成し、来客とendless戦闘で任意アートとして使う。マスター・プロンプト・処理スクリプト・二値透過・足元48/108・共有80色の来歴はローカル台帳に記録。公開・再配布・Mac同梱の許諾はpendingで、placeholder・画像のない環境・読込失敗時は従来のコード描画へ戻る。
- 画像のある来客は、生成アトラスの`move`と`recover`を歩行位相で交互に表示する2コマ歩行に、1pxの上下動・浅い前傾・小さな足元の粒を重ねる。停止中は`idle`、最初の停止は`exit`（会釈）フレーム。画像のないコード描画では、脚・腕・スカーフ・ポニーテール・三つ編み・提灯・本が歩行位相に合わせて動く。
- 汐見のリツカの生成デザイン：潮切りショートボブ＋高い潮尾、波打ちスカーフ、黒羽織・白シャツ・琥珀の帯、腰の短刀、潮図の巻物。紙灯のユメ：夜紫の長髪＋紙タグ付き三つ編み、折り紙リボン、生成りのブラウス＋製本エプロン、道具帯、本と提灯。
- どちらも来客とendlessのコード描画戦闘の両方に反映される（手動アリーナのボス枠はリュミエのまま）。来客は非戦闘・非HUDのまま。
