# 通常待機中の静かな来客

2026-11-12の追加依頼「通常の待機時間にも定期的にボスキャラが訪ねてきてウロウロ」への実装。WebプレビューとMac壁紙に共通。

- auto/restの有効な待機時間だけを数え、初回75〜105秒、退室後120〜180秒で訪問。非表示・一時停止・Reduce Motion・スリープの既存停止を維持し、復帰時に時間を取り戻さない。
- 綴星リュミエ／汐見のリツカ／紙灯のユメの3人。別seed乱数のバッグで一巡し、同じ人が連続しない。一度に1人だけ、左右から入り、書斎の手前で歩く・立ち止まる。45〜60秒経過で退室を始め、最長90秒。
- 戦闘・homeへの切替で直ちに解除。敵/弾/HP/得点/戦績/アーケード時計を作らず、生活・戦闘の乱数や対戦予定を消費しない。自動対戦頻度offは来客を止めない。
- 既存リュミエの任意アートとコード描画の2人を再利用。承認済み画像は不変更。HUD/戦闘背景なし。書斎外キャプションに訪問者名を表示。
- ホストAPI `command(game, 'visitors', false)`で抑制可。DSHはこれを指定し、待機室へ来客を持ち込まない。新しい個人設定は保存しない。

`src/companion/visitors.ts`が進行、`visitor-art.ts`が描画のみを担当。Node6件とSwift2宣言（1件は3引数）の回帰を追加。30分相当/複数fps/既存状態の完全一致を検査。静止描画は確認済みだが、実壁紙上の連続動作・負荷・他Macでの受入は未実施。
