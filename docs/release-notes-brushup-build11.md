## 内容（Build 10までの積み上げ）

「くじらの散歩道」のMacアプリを、**おっとりしていて、ときどき強い**個性が伝わるように磨いた個人検証用ビルド。普段は静かな壁紙のまま、手元でだけ小さく応え、遊ぶときはテラスで3連戦します。

- **呼んでみる（プレビュー限定）**: 書斎で休んでいる時だけ、20秒に1回。承認済みの正面フレームで約1.2秒応え、「ん、呼んだ？」をシーン外に表示。世界・乱数・対戦予定は変えず、**壁紙の描画は呼びかけの有無で完全に同じ**
- **背景をすぐ選べる**: シーン下の「背景」で夕凪・月夜・雨音を切り替え。標準の夕凪が必ず先頭にあり、読み込めた背景だけを候補に出す。「雨音」は景色で、音は鳴らない
- **生活の小さなキャプション**: 常時の対戦勧誘文をやめ、「少しだけ、うとうと。」「雨音を、聞いている。」など、いまの様子を短く表示。帰宅後は「ふう。書斎がいちばん。」
- **導線の整理**: 「おっとり。ときどき、つよい。」のタグライン。設定と作品説明を分け、停止理由と再開方法を一箇所に。ゲームの帰宅は「書斎へ戻る」（壁紙ON/OFFとは別操作）
- **About の小さな姿**: 既存シートの正面フレームを整数倍で表示（Web/Mac）

## 動作環境と起動（他のMac）

- Apple Silicon（arm64）、macOS 14以降。Intel Mac・macOS 13以前は対象外
- ダウンロードした `SHA256SUMS.txt` で整合を確認する

  ```sh
  shasum -a 256 -c SHA256SUMS.txt
  ```

- DMGを開き、「くじらの散歩道.app」を Applications へドラッグ（任意）
- **初回はアプリを右クリック →「開く」**。未公証のため、ダブルクリックだけでは警告が出ることがある。macOS全体の保護設定は無効にしない。個別許可は「システム設定 > プライバシーとセキュリティ」から
- 初回はプレビューのみ。壁紙ONは明示操作。元の壁紙設定・ログイン自動起動は変更しない
- 音・通信・アクセス解析・自動アップデートはない
- 旧版が起動中なら終了してから新版を開く
