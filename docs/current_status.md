## 今回の変更

- **背景を3種類に**：夕凪（承認済みの標準）に加え、同じ書斎の「月夜」「雨音」を追加。各背景は480×270px・192色と、同じマット生成器で作る1024×576pxのワイドマットを持つ。承認済み構図・家具・歩行帯を参照してGPT Imageで再構成し、ローカル画像処理したもの。キャラクター16コマと夕凪の背景は変更していない。
  - Mac：プレビューのツールバーとメニューバーの「背景」から切替。選択は保存され、次回起動時に復元される（5つ目の保存設定）。
  - Web：「作品について」の「背景」で切替（セッション内のみ）。
  - 壁紙・プレビュー・書斎内の小事件のすべてが選択中の背景を使う。手動フルルートでは書斎区間の背景にだけ反映され、屋外ステージは従来どおり。
- **メモリ使用量の実測と表示**：ProcessMemory（TASK_VM_INFO.phys_footprint）を追加し、メニューバーに「メモリ使用量（プロセス）」を表示。「作品について」にも概算を表示する。
  - 実測（ローカル素材・背景3種を読み込んだ状態、描画器のみのプロセス）：エンジン読込9.5MB → 2048×864描画後10.9MB → 1000×680描画後11.5MB。
  - ウィンドウ付きアプリの起動スモーク（プレビューのみ・非表示扱い）：31.6MB。
  - 100MB以上に見える分の大半は、AppKit／JavaScriptCore／ウィンドウサーフェス／GPUまわりの固定オーバーヘッドで、アプリが持つ素材・描画画布は10MB前後。今回、プレビューを閉じたときにウィンドウ・ビュー・ボタン参照を解放するようにし、手動戦闘が終わったら3600pxのワイドステージキャッシュ（数MB）を解放するようにした。
- **帰属とライセンスの整理**：ユーザーの意向により、一般公開しない方向のまま、キャラクター「DeepSeekちゃん（クジラ娘）」の原案・デザイン・世界観は大元のファンコミュニティ／原案者に帰属するものとして明記した。本プロジェクトはキャラクター・原案の権利を主張せず、独自ライセンスを付与しない。CREDITS／ART-LICENSE／README／アプリ内のAbout／Webの作品についてに反映済み。DeepSeek社との提携・承認はない。この帰属表示は公開・再配布の許諾を意味しない。
- 既存の v0.5 改善（1024×576ワイドマット、整数倍描画、環境演出、書斎内の小事件）は維持している。

## 現在の実装

- **壁紙**：主画面の解像度から2倍以上の整数倍率を選び、1ドットを正方形で描く（2048×864は3倍、1920×1080は4倍）。16:9以外はワイドマットで部屋の続きを表示し、端の1px引き伸ばし帯を出さない。マット中央の480×270pxは各背景と1pxも変えない（テストでbyte一致）。
- **背景3種**：`private-art/runtime/scene/variants/{night,rain}/{scene,matte}.png`。`private-art/runtime/variants.json` がID・ラベル・パスを持つ。Viteはローカル版だけ静的importし、クリーンなチェックアウトの既定版には入らない。
- **環境演出**：[ambience](<../src/render/ambience.ts>)が海面のきらめき（11〜22個、2〜3px×1px）、窓辺の光の粒（12個＋尾）、吊りランプ／机ランプの明滅、ときどき窓を横切る小鳥を生成。CanvasとCoreGraphicsが同じ矩形コマンドを消費し、新しい画像・音は足していない。
- **静かな生活と小事件**：普段は待機・歩行・振り向き・睡眠。帰還後3〜5分（設定で短縮／なし）で書斎内に2〜3体の来客が現れ、10〜15.6秒（8シード平均12.5秒）で片付けて紙吹雪・星・リング・お茶のあと静かに帰る。カメラ0固定、章題・HUD・横スクロール・ボスはなし。`demo`（事件を見る）も同じ。
- **手動フルルート**：4エリア・3600px・12セクション＋桟橋のボス、HUD・章題・GO・区間リトライ。手動は前面プレビューだけ。壁紙は手動中も静かな生活を表示する既存分離を維持。
- **Mac**：AppKit／CoreGraphics／JavaScriptCore／CoreText、Swift外部依存ゼロ。壁紙は主画面の非アクティブ・クリック透過NSPanel。元壁紙のURL取得・保存・書換えなし。
- **メモリ表示**：メニューバーにプロセスfootprintを表示（約4秒ごと更新）。プレビューを閉じるときにウィンドウとビューを解放。手動戦闘後にワイドステージのCGImageキャッシュを解放。
- 保存するのはアプリ自身の一時停止・省電力・小事件頻度・エフェクト量・背景の5設定のみ。戦闘・押下キー・壁紙ONは保存しない。

## 既存の絵と壁紙の保全

- 承認済みの80×112・16コマ、アトラス320×448、足元40/108、夕景480×270pxは変更していない。静かな生活の歩行範囲134〜362・床236・まばたき・睡眠も維持。
- 追加背景の月夜・雨音はローカル生成（480×270px、各1024×576pxマット、外周は緩く暗化）。生成元は `private-art/production/build-wallpaper-variants.py` と `build-matte.py` で、Git対象外。
- 敵・小物・技は独自の仮ピクセル図形のまま。音は常時無音、強い点滅・画面揺れなし。
- 壁紙の一時停止・静止・Reduce Motion・非表示／セッション／スリープ停止を弱めない。個人用の保存設定以外は持たない。
