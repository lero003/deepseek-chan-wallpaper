# 現在の状態 / 引き継ぎ

更新: 2026-11-11 · 非公開Web／個人用Mac試作 · 壁紙ブラッシュアップ v0.5（ワイドマット・整数倍描画・環境演出・書斎内の小事件 / アプリBuild 6）

## 今回のブラッシュアップ（壁紙優先）

- **横長画面の左右のびを解消**。ユーザーの2048×864画面では、480×270書斎の左右に約256pxずつ「1pxを伸ばした帯」が出ていた。これを1024×576pxの**ワイドマット**（中央=承認済み書斎）に置き換え、周囲だけ同じ部屋の続き（壁板・梁・床板・蔦・右側の机の続き・外側の緩い暗化）を表示する。中央480×270pxは1pxも変えていない（`(272,153)`へ原寸コピー、テストでbyte一致を確認）。
- **整数倍のピクセル描画**。画面のピクセル数から2倍以上の整数倍率を選び、1ドットを同じ大きさの正方形で描く（2048×864は3倍、1920×1080は4倍、1440×900は3倍）。3.2倍のような端数倍で起きていたドットの大きさの揺れ・ちらつきをなくした。狭いプレビューだけは部屋が小さくなりすぎないよう比率フィットにする。
- **環境演出（コードのみ）**。[ambience](<../src/render/ambience.ts>)が海面のきらめき（2〜3pxの光、11〜22個、3.5〜9秒の個別の明滅）、窓辺の光の粒（12個＋尾）、吊りランプと机のランプの明滅（8.6秒／11.3秒）、ときどき窓を横切る小鳥（118秒ごと24秒）を生成する。CanvasとCoreGraphicsが同じ矩形コマンドを使い、新しい画像・音は足していない。
- **自動イベントを書斎内の「小さな事件」へ**。`route 'room'`を追加し、待ち時間のあと書斎の中にスライム／ポップアップが2〜3体（たまに2波目）現れる。カメラは0固定、章題・HUD・横スクロール・ワイド背景・ボスはなし。6種類の来客構成をシードで選び、10〜15.6秒（8シード平均12.5秒）で倒して紙吹雪・星・リング・お茶の演出のあと静かに帰宅する。`demo`（事件を見る）も同じ書斎内事件。
- **手動のフルルートは不変**。4エリア・3600px・12セクション＋桟橋のボス・HUD・章題・GO・区間リトライ。手動はプレビュー内だけで、壁紙は静かな生活を表示する既存分離を維持。
- Web版も同じワイドマットと整数倍Canvasを使う。マットを読み込めない場合は従来の部屋表示へ安全にフォールバックする。

## 既存の絵と壁紙の保全

- 承認済みの80×112・16コマ、アトラス320×448、足元40/108、夕景480×270pxは変更していない。静かな生活の歩行範囲134〜362・床236・まばたき・睡眠・振り向きも維持。
- ワイドマットはローカル生成（1024×576px、中央以外は同じ部屋の続き、外周は緩く暗化）。生成器は `private-art/production/build-matte.py` で決定的、Git対象外。既存の生成マスター・参照・QA画像もGit対象外のまま。
- 敵・小物・技・左右書棚は独自の仮ピクセル図形のまま。専用の78コマ等を制作済みとは扱わない。音は常時無音、強い点滅・画面揺れなし。
- MacはAppKit／CoreGraphics／JavaScriptCore／CoreText、Swift外部依存ゼロ。Node・Webサーバー・ネット接続は実行時に不要。
- 壁紙はOS設定ではなく主画面の非アクティブ・クリック透過NSPanel。元壁紙のURL取得・保存・書換えなし。壁紙ONは手動、次回自動復元・ログイン自動起動なし。
- **手動は前面プレビューだけ。手動ゲーム中の壁紙は従来の静かな生活を表示。** グローバルキー捕捉なし。フォーカス喪失・スリープで押下解除、復帰に1秒猶予。
- 既存の一時停止・静止・Reduce Motion・非表示／セッション／スリープ停止を弱めない。個人用の停止・省電力・事件頻度・エフェクト量のみ保存し、戦闘・押下・壁紙ONは保存しない。
