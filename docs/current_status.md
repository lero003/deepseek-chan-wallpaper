# 現在の状態 / 引き継ぎ

更新: 2026-11-11 · 非公開Web／個人用Mac試作 · Fighters MVP v0.4（横スクロール乱戦・4エリア12セクション / アプリBuild 5）

## 現在の実装

- 「くじらの散歩道」の追加モードとして、**DeepSeekちゃんファイターズ**の縦切りを実装。[構成・操作・調整値・残タスク](<fighters-mvp.md>)が今回の正本。
- **ファイナルファイト式の横スクロール**：書斎→海辺のテラス→潮風の遊歩道→夕凪の桟橋の4エリア（3600px）。12セクションを歩いて進み、区切りでカメラ固定・左右から敵が登場。1〜2波を倒すとGO矢印で次へ。フルルートはボット実測150〜162秒。
- スライム3種（青速い／金硬い）、ポップアップ3種（赤連射／白硬い）、ボス。色・大きさ・HP・弾数が変化。区間クリアでHP+1、敗北はその区間からリトライ。オートは短縮ルート（約68秒）で帰宅。
- J/Zの3段コンボ（1/2/3ダメージ）、K/Xの無敵ステップ、L/Cのゲージ必殺、Escのゲームポーズ。奥行き判定・予備動作・反動・ヒットストップ。戦闘中の台詞・吹き出しはなし。
- 通常は静かな生活。帰還後3〜5分待って小事件、頻度変更／オフ可。「事件を見る」で待たずに確認。初回はボス付き、その後は日常50%／雑魚35%／ボス15%。空振り・自己クローズ・勝利後の滑り、停滞復旧と帰還上限を持つ。
- [共通コア](<../src/fighters/game.ts>)・[戦闘](<../src/fighters/combat.ts>)・[敵AI](<../src/fighters/enemy-brain.ts>)・[ディレクター](<../src/fighters/director.ts>)・[描画計画](<../src/fighters/render-plan.ts>)・[ピクセル描画](<../src/fighters/art.ts>)を分離。CanvasとCoreGraphicsは同じコマンドを描く。60Hz更新／30fps、低電力15fps。
- **v0.4の作り込み**：ステージを3600pxに拡張し、4エリア・12セクション・2波の横スクロール乱戦へ。左右からの敵の登場、アリーナ固定カメラ、GO矢印、区間リトライ、敵バリエーション（色・大きさ・弾数）、パララックス、空の滑らかなグラデーション、前景の植木、接地影を追加。
- **v0.3の作り込み**：セリフを外し、海辺のテラス（空・海・島影・灯台・欄干・デッキ・街灯・ベンチ・植木・提灯）を追加。扉への移動演出、章題、紙吹雪、斬撃軌跡、着弾フラッシュ、衝撃波、描画順の修正も追加。
- **v0.2の作り込み**：敵3種を表情・予備動作・被打・退場まで描き直し、本／羽ペン／回転の武器軌跡、命中の衝撃波と「ぽふっ」、紙吹雪、ボスの本気モード、ピクセルHUD・章題バナー・リザルト紙面を追加。左右の書斎も壁・床色から生成する書棚・額縁・ランプ・植木・茶器まで作り直した。

## 既存の絵と壁紙の保全

- 承認済みの80×112・16コマ、アトラス320×448、足元40/108、夕景480×270のPNGは変更していない。静かな生活の歩行範囲134〜362・床236・まばたき・睡眠も維持。
- 敵・小物・技・左右書棚は独自の仮ピクセル図形。専用の78コマ等を制作済みとは扱わない。音は常時無音、強い点滅・画面揺れなし。
- MacはAppKit／CoreGraphics／JavaScriptCore／CoreText、Swift外部依存ゼロ。Node・Webサーバー・ネット接続は実行時に不要。
- 壁紙はOS設定ではなく主画面の非アクティブ・クリック透過NSPanel。元壁紙のURL取得・保存・書換えなし。壁紙ONは手動、次回自動復元・ログイン自動起動なし。
- **手動は前面プレビューだけ。手動ゲーム中の壁紙は従来の静かな生活を表示。** グローバルキー捕捉なし。フォーカス喪失・スリープで押下解除、復帰に1秒猶予。
- 既存の一時停止・静止・Reduce Motion・非表示／セッション／スリープ停止を弱めない。個人用の停止・省電力・事件頻度・エフェクト量のみ保存し、戦闘・押下・壁紙ONは保存しない。

## 実行済みの検証

- `npm run check`／`npm run build`：型検査・**Node 71テスト**・既定5素材の再現性・制作版の透過／接地／局所まばたき／SHA-256成功。
- `npm run mac:test`／`npm run mac:test -- --local-preview`：仮素材・制作版とも**Swift Testing 16テスト**。生活と全ゲームそれぞれ15/30/60fps各30分を実際のJavaScriptCoreとV8で完全比較。個数上限・コマンド・非フォーカス停止・壁紙の別表示・ネイティブ描画を確認。
- `npm run mac:build -- --local-preview`：Release Build 5、アドホックHardened Runtime署名、アイコン、plist、全同梱14ファイルのZIP再展開一致・署名・システムPATHだけでの単体起動とFighters自己検証成功。[ローカル台帳](<../private-art/macos-out/latest.json>)に実際の成果物・SHA-256・未確認項目を記録。
- 最終成果物：`private-art/macos-out/20261110212158-c3cbc735/KujiraWallpaper-Fighters-MVP4-arm64-local-preview.zip`（SHA-256 `1e8c43aba1ac772f555df3fa960d7134bfc7569d41df5feaa3f187e4ff848697`）。
- ネイティブ描画の確認用に `--render-manual --time N` を追加し、実際の手動HUD・リザルト・ボス戦をPNG出力して目視確認した（デスクトップの録画ではない）。
- 最終アプリの `--smoke-test`：プレビュー・メニュー・ゲーム操作UI生成、mode=auto、壁紙OFF、手動フォーカスなしで成功。ただし環境は可視面なしのためタイマー停止。可視操作・デスクトップ描画の合格ではない。
- 雑魚／ボスのネイティブPNGを画像確認。**描画器の出力であってデスクトップの録画／スクリーンショットではない。**
- 独立レビューは仮素材／制作版各128seedのオートが全帰還、追加ブロッカーなし。修飾キー付きkeyupで歩き続けるWeb入力の不具合を修正し、EventTargetのみの回帰テスト追加済み。
- 過去のWebKit可視スモークはhidden／occluded前提で未完了のまま。[検証ツール](<../tools/webkit-smoke.swift>)の可視性ガードを弱めない。通常Safari／Chromeの手動・実機CPU測定と区別する。
- Playwright・専用ブラウザー・追加npm／Swift／Pythonパッケージは導入していない。Habitatは既存npm検証を選ぶ根拠として使用、依存・グローバル環境の変更なし。
