# 現在の状態 / 引き継ぎ

更新: 2026-11-10 · v0.1 非公開Webプロトタイプ

## アートの現在地

- ユーザーから現行のプログラム描画キャラは「デザインが違う」と指摘あり。現行16コマは初期仮素材・見た目未採用で、合格テストをデザイン承認と扱わない。
- ユーザー提供の具体的な参考画像を使い、GPT Imageバックエンドで3方向の基準絵を生成して画像として確認。髪飾り・白フリル・紺の服・淡色の尾・半目の表情を合わせた。ユーザー承認はまだなく、アプリには未反映。
- 参考メタデータ・生成PNG・生成プロンプト・レビュー履歴はGit対象外に分離。[アート方針](<art-direction.md>)に識別点と制作ゲートを記載。

## 実装済み

- TypeScript + Canvas 2D。480×270の安全領域、nearest-neighbor拡大、別比率への壁・床の拡張。
- 独自ドット絵のクジラ娘1体（青い髪・クジラの尾・メイド風エプロン）、海辺の書斎1舞台、16コマ。待機・歩行・振り向き・睡眠。
- 60Hz固定更新、seed付き乱数、接地範囲と床上の障害物、自然行動の滞在時間と睡眠クールダウン。
- 通常30fps／手動省電力15fps。一時停止、タブ非表示、pagehide・freeze、長い復帰差分の破棄、Reduce Motion・手動静止。
- モーダル内クレジット、画像エラー時の静止フォールバック、全素材の台帳・SHA-256・再現生成。
- ループバック限定のVite開発／プレビュー。静的ビルドは相対パス。公開デプロイなし。

## 判断と境界

- Web試作だけが今回の対象。macOS壁紙ホストや『猫の散歩道』のソースは未調査・未統合。壁紙ON/OFF、メニューバー、クリック透過、元壁紙復元は未実装。
- 現在のクジラ娘は、DeepSeekちゃん（クジラ娘）をモチーフにした独自の非公開ファンアート解釈。既存イラストの複製や公式ロゴは使っていないが、権利者の許諾を示すものではない。Web公開・GitHubでの公開画像配布・Mac同梱は許諾確認後。
- ライセンスはコード・アートとも未設定。`private`や`noindex`は公開防止機構ではない。
- 低電力設定はWebの手動15fps（Save-Dataがあれば初期値へ反映）。macOS低電力モードとの連携ではない。
- 画像は同一ビルドのローカル素材。サービスワーカーはなく、Webの初回オフライン起動は保証しない。
- 依存追加を最小化。テストはNode標準。Playwright・専用ブラウザーを再導入しない。
- Habitat 1.1.1で空フォルダと構成作成後を確認。npm以外の環境変更を避け、lockfileの自動ブラウザー依存を確認し、インストールスクリプトを無効化。秘密情報や個人データは不要。

## 実行した検証

- `npm run check`: 型検査、ユニットテスト、生成素材5ファイルの一致が成功。
- `npm run build`: 最終状態で29ユニットテスト・型検査・素材検証を再実行後、Viteの静的ビルド成功。
- テスト内で15/30/60fps各30分の世界一致、複数seed各30分の衝突・状態遷移を検証。実時間のブラウザー負荷試験ではない。
- 背景PNGとアトラスPNGを画像として確認。クジラ娘は16コマを4倍・8倍に拡大し、顔・尾・足元・睡眠姿勢を目視調整。背景に合成した2倍プレビューでもコントラストとサイズを確認。Web画面・ブラウザー操作の検証ではない。
- `npm run preview`で <http://127.0.0.1:4173/> を起動。NodeのHTTPスモークでHTML、相対URLのJS/CSS/SVG、画像3件の配信とバイト一致を確認。ブラウザー実行の検証ではない。
- ローカルMarkdownリンクとドキュメント・ソースの末尾空白チェックが成功。
- ユーザー指示の同期先はPrivateの `lero003/deepseek-chan-wallpaper`。空リポジトリであることを確認し、ローカルGitは `main` で初期化、同リポジトリを `origin` に設定。初回同期対象は本体と既存仮素材で、参考画像と新しい生成候補は除外する。Public化やPages設定は変更しない。
- ビルドは `dist` をクリアしてから生成するようにした。現段階の出力をそのまま公開配布用パッケージとは扱わない。
