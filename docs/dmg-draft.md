# ドラフトDMG（非公開リポジトリ）の配布と試用

## これは何か

「くじらの散歩道」Fighters MVP4 の**個人検証用ドラフト**。非公開のGitHubリポジトリに置く**下書きリリース（Draft Release）**で、公開リリースではない。下書きの間はリポジトリの共同作業者以外には見えず、公開・一般配布を意味しない。

- 対象: Apple Silicon（arm64）、macOS 14以降
- 署名: アドホック署名のみ。Appleの公証なし
- 初回起動はプレビューのみ。壁紙は明示操作でON
- 元の壁紙設定・ログイン自動起動は変更しない
- 音・通信・解析・自動アップデートはない
- 素材の権利・公開許諾は未確認。**再配布・公開アップロードをしない**

## 他のMacで試す手順

1. 非公開リポジトリの [Releases](https://github.com/lero003/deepseek-chan-wallpaper/releases) から、下書き `fighters-mvp4-draft` の DMG を取得する（アクセス権のあるアカウントでログインするか、作成者がDMGをAirDrop・USB等で手渡す）。
2. `SHA256SUMS.txt` で整合を確認する。

   ```sh
   shasum -a 256 KujiraWallpaper-Fighters-MVP4-draft-arm64.dmg
   ```

3. DMGを開き、「くじらの散歩道.app」を Applications へドラッグする（任意）。
4. アプリを**右クリック →「開く」**で起動する。未公証のため、ダブルクリックだけで警告が出る場合がある。macOS全体の保護を無効化しない。個別許可は「システム設定 > プライバシーとセキュリティ」から行う。
5. プレビューで動作を確認し、必要なら「壁紙にする」。終了はメニューバーから。

- [ ] 壁紙ON/OFF、クリック透過、元の壁紙が戻る
- [ ] Space／フルスクリーン／スリープ復帰
- [ ] 終了後にプロセスが残らない
- [ ] 30分程度のCPU・メモリ・発熱（実時間）

## 既知の制限

- Intel Mac、macOS 13以前、公証済み配布、自動更新、音声には対応していない。
- 背景・敵・技は共通描画コマンドで組んだ仮ピクセル素材。手描きの完成素材ではない。
- 実機の可視操作・壁紙ON/OFF・スリープ・実時間30分負荷は、作成環境では未確認。テスト結果を共有してほしい。
- アプリ内の素材は個人用の生成素材。権利・許諾を確認していないため、公開・再配布・ストア提出をしない。

## リリースの扱い

- 下書きのまま維持し、権利確認と実機受け入れが終わるまで公開しない。
- リポジトリの可視性・Pages・自動起動は変更しない。
- チェックサムとビルド記録は `private-art/macos-out/`（Git対象外）とリリース添付の `SHA256SUMS.txt` に残す。
