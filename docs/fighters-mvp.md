# DeepSeekちゃんファイターズ — 固定アリーナ試作

## 今回の形

「くじらの散歩道」の任意の対戦モード。距離を歩く横スクロールではなく、**開戦 → 雑魚戦2ラウンド → 美少女AIライバルとの一騎打ち → 決着 → 書斎へ帰宅**をひとまとまりにする。1セット3連戦で、毎セット最後に同じボスが登場する。追加の敵・ボス・舞台へは広げない。

- **固定の海辺のテラス**：480×270pxの画面、カメラ960固定。次の戦いを始めるために歩く必要はない。左右・奥行き移動は間合いの調整に使う。背景は承認済み書斎を参照して生成した夕暮れのテラス（A案・ローカル専用）。画像がない環境はコード描画テラスへ戻る。壁紙・書斎の小事件にはこの背景を使わない。
- **第1ラウンド**「潮風の腕ならし」：既存スライム／ポップアップ計3体。
- **第2ラウンド**「テラスの挑戦者」：同じ2種のバリエーション計4体。雑魚戦の合間には短い休息とHP+1（上限5）。
- **最終ラウンド**：綴星リュミエ、HP30。4種類の予告技とHP半分からの本気モード。アリーナでは召喚せず、最後まで1対1。突進（思索のステップ）は予備動作中に床へ進行方向の警告ラインを描き、反応できるようにする。
- **開始と区切り**：各ラウンドは開戦準備から始める。イントロ・ボス対面・休息では、入力だけでなく攻撃／被弾／敵弾の更新自体を止める。ボスは対面演出中から見えるが、開戦前には戦闘オブジェクトとして存在しない。開始時は「READY」、開戦の瞬間は「FIGHT」を出す。
- **アーケードの得点と時計**：各ラウンドは90秒。命中は実ダメージ×25点×コンボ倍率（5コンボごとに最大4倍）、KOは雑魚100点／ボス1000点。クリア時に残り秒・残HP・ノーダメージのボーナスを加算する。首尾よく速いほどRANKが上がる。
- **決着と結果**：勝利後は短い余韻と暖色フェードで帰宅。RANK・SCORE・最大コンボ・CONTINUE回数・命中／空振り／回避／必殺／被弾・所要時間を表示する。壁紙で過ごした時間や前の対戦の記録は混ぜない。
- **敗北と再戦**：敗北・TIME UPはそのラウンドの開戦準備から、HP全快・ゲージ0で再挑戦。失敗したラウンドで稼いだ得点はクリア済みチェックポイントへ巻き戻し、CONTINUE回数だけを残す。勝利後の「もう一戦」は第1ラウンドから新しい計測で始める。

旧4エリア・3600px・12区間のデータは内部の回帰確認用に残すが、通常の「遊ぶ」入口には使わない。

## 静かな壁紙との境界

壁紙を常時ゲーム画面にはしない。自動モードと「事件を見る」は、これまでどおり**書斎の中の10〜15秒程度の小事件**。6種類の来客構成から選び、カメラ0、章題・HUD・ボスなしで終え、お茶と紙吹雪のあと生活へ戻る。背景3種、ワイドマット、承認済みキャラクター16コマは保全する。

手動対戦はプレビュー内だけ。Macの受動的な壁紙面には静かな生活を描き続け、入力・HUD・ボスを流さない。壁紙ONはユーザー操作であり、ビルドやテストではONにしない。

## 操作

「テラスで3連戦」で開始。「事件を見る」は書斎内の小事件。

| 操作 | キー |
| --- | --- |
| 間合い・奥行き調整 | WASD / 矢印 |
| 3段コンボ | J / Z |
| 回避 | K / X |
| ゲージ100の必殺 | L / C |
| 対戦だけのポーズ | Esc |

- 開戦準備・休息・決着中は攻撃ボタンも無効。「このラウンドを再挑戦」「もう一戦」「壁紙へ戻る」は状態に合わせて表示する。
- Webはプレビューを選択してキー操作。ラウンド名とフェーズを読み上げ、残HP／時計の更新ごとには通知しない。
- Macは前面プレビューのNSResponderのみ。修飾キー・キーリピート・blur・ウィンドウ切替で押下を解除し、復帰時は1秒の猶予。グローバルキー捕捉はない。
- フォーカス喪失・ゲームポーズでは戦闘時計も止める。ヒットストップは所要時間に含む。既存の静止・Reduce Motion・非表示／スリープ停止は弱めない。音は無音。

## ボスの制作案

**綴星リュミエ — 琥珀の思考家**。Claudeの文章・思考を着想にしたオリジナルのAI擬人化案。亜麻色の髪、琥珀色の瞳と袖、文章が重なる紙のマント、万年筆を持つ少女。公式キャラクターでも、Anthropic社との提携・承認でもない。従来の男性仮ボスを同じ1枠で置き換える。

- GPT Imageによる生成マスターから、8姿勢の透過ピクセルシートを制作。承認済みDeepSeekちゃんの原本・16コマは変更しない。
- 制作アートと来歴はGit対象外。ローカル専用で、デザインのユーザー最終確認・公開／再配布許諾を得たという意味ではない。
- ローカル素材がない環境は独自の簡易美少女ピクセル描画。`--mode placeholder` と、明示的なローカルプレビュービルド以外のMac準備には制作ボスを含めない。
- ボス画像の読込失敗／不正サイズでも、共有の仮描画へ戻す。台帳にある既存素材の整合性検証は弱めない。
- テラス戦闘背景の生成アート（A案）は統合済み。主人公の専用戦闘姿勢、雑魚2種の完成アート、動作の自然さ・難易度の実機受け入れは別工程。
