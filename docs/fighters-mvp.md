# DeepSeekちゃんファイターズ — 横スクロール乱戦MVP

## 今回の形

「くじらの散歩道」の追加モード。**手動で遊ぶときだけ**、ファイナルファイト系の横スクロール乱戦になる。一方向に歩き、画面の左右から湧く敵を片付け、区切りごとに先へ進む。フルルートは**12セクション（各1〜2波）＋桟橋のボス**で、人のプレイでおよそ3分。壁紙の自動モードはゲームモードに切り替えず、**書斎の中で起きる10〜15秒の小さな事件**だけを静かに見せる。

- **手動の4エリア・3600px**：夕凪の書斎 → 海辺のテラス → 潮風の遊歩道 → 夕凪の桟橋。カメラはヒロインを追従し、各エリアの入口で章題バナー。
- **12セクション**：一定位置に達するとカメラが固定（アリーナ）され、左右の画面外から敵が歩いて入ってくる。1波目を倒すと2波目、両方倒すと「GO」の矢印が出て次へ進める。
- **敵のバリエーション**：スライム3種（青・速い／金・硬い）、ポップアップ3種（赤・連射／白・硬い）、ボス。色・大きさ・HP・弾数・予告が変わる。
- **ボス**：桟橋の奥で待つキャプテン・トークナガ。HP30、4パターン（長文弾幕／召喚／突進／脚注）＋HP半分で本気モード。手動ルートだけに登場。
- **手動**：3段コンボ（1／2／3ダメージ）、回避、ゲージ必殺、ポーズ。区間クリアでHP+1、敗北時はその区間から再挑戦。
- **壁紙の自動事件**：待ち時間のあと、書斎の中にスライム／ポップアップが1〜3体現れる。カメラは0固定、章題・HUD・横スクロールなし。6種類の来客構成（色・数・2波目）からシードで選び、10〜15秒で倒して、紙吹雪とお茶の演出のあと静かに帰宅する。ボスは出ない。
- **帰還**：勝利後は暖色のフェードで書斎へ戻り、手動ならリザルト、壁紙なら静かな生活へ戻る。

## 操作

「事件を見る」で待たずに書斎内の小事件、「遊ぶ」で最初からフルルート（手動）。WASD／矢印で移動、J/Zで3段コンボ、K/Xで回避、L/Cでゲージ必殺、Escでポーズ。「壁紙へ戻る」で静かな生活へ、「もう一度遊ぶ」で区間リトライ。手動のフルルートはプレビュー内だけで、壁紙は静かな生活のまま。

Webはプレビューを選択してキー操作。Macは前面プレビューのNSResponderだけが受け取る。修飾キー・キーリピート・blur・ウィンドウ切替で押下を解除する。グローバルキー捕捉はなく、壁紙側は入力を受け取らない。音は常時無音。

## 見た目と演出

- **パララックス**：空の雲・鳥・海面・前景の花びらを別速度で移動。sun光条、海面の反射、灯台、島影、街の明かり、係留船。
- **エリア**：テラスは木のデッキ・欄干・パーゴラ・提灯。遊歩道は石畳・石の欄干・花壇・木のアーチ・吊り花。桟橋は板張り・ロープ柵・係留柱・木箱・ランタン。各所に接地影と太陽の照り返し。
- **戦闘**：三日月の斬撃、着弾の白フラッシュ、地面の衝撃波、殴り合いの土煙、歩行時の砂ぼこり。ヒットストップと暖色フラッシュ。敵は被弾時に白く光る。
- **HUD**：ピクセルハート、セグメントゲージ、コンボ、エリア名、区間ピップ、ボスバー、章題、GO矢印、リザルト紙面。
- **セリフなし**：戦闘中の吹き出しは生成しない。ボスの長文は周回する書類で表現。
- **壁紙の事件演出**：書斎のマット背景にそのまま重ね、章題・GO・HUD・ワイド背景を出さない。勝敗の紙吹雪・星・リング・お茶・土煙は既存の矩形コマンド。`effectsLow` では紙吹雪を控えめにする。
- **環境演出**：通常の静かな生活では海面のきらめき、光の粒、ランプの明滅、小鳥がゆっくり動く。

## 実行済みの検証

- `npm run check`／`npm run build`：型検査・**Node 93テスト**・既定5素材の再現性・制作版の透過／接地／SHA-256・ワイドマットの中央一致。
- `npm run mac:test -- --local-preview`：**Swift Testing 16テスト**。生活世界と全ゲームを15/30/60fps各30分、V8とJavaScriptCoreで完全一致比較。
- 12セクションの完走（ボットで約145秒でボス到達）、左右からの出現、エリア遷移、区間リトライ、手動ルートのボス、30分の個数上限、フォーカス・停止・壁紙分離をテスト。
- 壁紙の小事件：6種の来客、カメラ0固定、部屋の外へ出ないこと、10〜15秒で帰宅、ボスなし、自動では負けないこと、`play`中の安全なフルルート移行、30分で28事件（4シード×15fps）の完走をテスト。
- ネイティブ `--render-room-event --width 2048 --height 864` などで、実際の描画器による書斎内事件とワイド画面の確認PNGを生成。
- 3600px全域の塗り（右端欠けの回帰テスト）、半透明のCanvas／CoreGraphics適用、描画命令の純粋性と有限性。
- ネイティブ `--fighters-self-test`／PNG書き出し（テラス・遊歩道・桟橋・ボス・リザルト・書斎内事件）を目視確認。**実際のウィンドウ操作やデスクトップ録画ではない。**
