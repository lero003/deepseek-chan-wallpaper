# 静かな来客 Build 12（個人テスト用）

普段の書斎へ、綴星リュミエ・汐見のリツカ・紙灯のユメが1人ずつ遊びに来ます。歩いたり立ち止まったりして、しばらくすると帰ります。初回75〜105秒、その後は退室から約2〜3分の待機時間。自動対戦を「なし」にしても訪問します。

来客は戦闘/HP/得点に影響せず、既存画像も変更していません。開始済みの対戦に切り替わると退室します。Web向け無限ボスラッシュの共有コアも同梱しますが、Macにその開始UIは追加していません。

Apple Silicon / macOS 14以降。DMGを開き「くじらの散歩道.app」をApplicationsへドラッグして起動してください。初回はプレビューのみで、壁紙表示は「壁紙にする」を選んだ時だけ。元の壁紙設定・ログイン自動起動は変更しません。
