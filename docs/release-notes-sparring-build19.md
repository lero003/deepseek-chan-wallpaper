# ゆっくり対戦 Build19 — 非公開プレリリース

ソースタグ: `sparring-build19`（`c9d3e83581e4fc82e7ca61df63c07ad4c0c4c25c`）。パッケージタグ: `sparring-build19-dmg`。コードのバージョンは非公開試作の0.1.0、Mac bundle buildは19です。この更新は一般公開・画像の再配布許諾ではありません。

**タグ・Releaseの整理について**: 2026-11-17のユーザー依頼で、非公開リポジトリ内の古いタグ・Release（Build6〜15系・ドラフト）を全削除し、このBuild19の1本だけにしました。履歴上のコミットは`main`にそのまま残っています。目的は本人の別Macでの個人利用のみです。

## 変更点

- 「リュミエとゆっくり対戦」（`mode: sparring`）を追加しました。固定テラスでリュミエ1人と穏やかに打ち合い続ける、眺める専用の練習試合です。HP・HUD・スコア・タイマー・勝敗なし、双方倒れません。
- 手動3連戦（小さな敵2ラウンド＋リュミエ、90秒・SCORE・RANK）を**壁紙OFFのときだけ**復元しました。壁紙をONにすると手動対戦は終わり、選んでいた書斎／ゆっくり対戦へ戻ります。
- 書斎モード（静かな生活6仕草・来客のリツカ／ユメ・背景5種）と全ディスプレイ同期壁紙はそのまま維持します。
- 元の壁紙設定・ログイン自動起動・システム設定は変更しません。壁紙ON/OFFは明示操作だけです。

## 使い方

1. DMGを開き、「くじらの散歩道.app」をApplicationsへドラッグします（任意）。
2. 起動するとプレビューが開きます。壁紙は「壁紙にする」を選んだときだけ表示されます。
3. モード選択で「書斎で過ごす」「リュミエとゆっくり対戦」を選べます。手動対戦は壁紙OFF時だけです。
4. OFF・終了でアプリのウィンドウが消え、元の壁紙が見えます。音・通信・解析・ログイン自動起動はありません。
