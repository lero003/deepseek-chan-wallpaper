## 内容

「くじらの散歩道」のMacアプリに、横スクロールを抑えた**固定アリーナの格闘アクション**を追加した個人検証用ビルド（Build 9）。普段は静かな壁紙のまま、手動のときだけ海辺のテラスで3連戦します。

- 雑魚戦2ラウンド → 綴星リュミエ（Claudeの文章・思考を着想にしたオリジナル美少女AI案）との一騎打ち → 決着 → 書斎へ帰宅
- 各ラウンド90秒。READY → FIGHT → 戦闘 → クリア → 次の相手
- 実ダメージ×コンボ倍率、KO、クリア時の残り秒・残HP・ノーダメージでSCORE。被弾・CONTINUE・速さでRANK（S/A/B/C）
- 敗北・TIME UPはそのラウンドから再挑戦。失敗ラウンドの得点はクリア済みチェックポイントへ巻き戻し、CONTINUE回数だけ残る
- ボスの突進は床に進行方向の警告ラインを表示
- 同じtickの「方向＋攻撃」が新しい向きで振れるよう修正
- 壁紙の小事件は従来どおり書斎内・10〜15秒・ボスなし。承認済みキャラクター16コマと背景3種は不変
