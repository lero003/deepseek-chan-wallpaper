# くじらの散歩道（仮）

海辺の小さな書斎で、青い髪のクジラ娘が歩き、立ち止まり、ときどき眠る。音のない、眺めるためのWeb試作です。

**v0.1 / 非公開プロトタイプ。Macの動く壁紙アプリではまだありません。**

現在の16コマは動作確認用の初期仮素材で、キャラデザインは未採用です。ユーザー提供の参考画像を基に、画像生成で新しい基準絵を制作しました。見た目の確認後にドット絵へ落とす方針で、まだアプリ内の画像は差し替えていません。制作順と識別点は[アート方針](<docs/art-direction.md>)を参照してください。

## 起動

Node.js 22.18以上（検証環境: 26.12.1）とnpmを使用します。実行時の外部ライブラリはなく、開発用依存はTypeScriptとViteのみです。

初回は依存定義・lockfile・scriptsを確認し、このプロジェクト内の開発用依存を導入します。インストール時のライフサイクルスクリプトは実行しません。

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run dev
```

開発用URL: <http://127.0.0.1:5173>。ポートが使用中なら停止し、勝手に別ポートへ移りません。

静的ビルドの確認:

```sh
npm run build
npm run preview
```

プレビュー用URL: <http://127.0.0.1:4173>。どちらもループバックだけにバインドします。終了は実行中のターミナルで `Ctrl+C`。ビルド成果物を直接 `file://` で開くのではなく、ローカルHTTP経由で確認してください。

## 操作

- 基本は眺めるだけ。待機・歩行・振り向き・睡眠を自律的に行います。
- 右下の「一時停止／再開」で止められます。
- 「作品について」に素材クレジット、静止表示、15fpsの省電力設定があります。開いている間も停止します。`Esc`で閉じられます。
- タブ非表示・ページの凍結・復帰後の大きな時間差は進行させません。手動の一時停止は自動解除しません。
- OSの「視差効果を減らす」設定では静止表示です。WebからmacOSの低電力モード自体を判定しているわけではありません。
- URLに `?seed=好きな文字列` を付けると行動を再現できます。設定・シードを外部送信したり永続保存したりしません。

## 検証

```sh
npm run typecheck
npm test
npm run assets:check
npm run build
```

Node標準のテストランナーを使用します。Playwright・専用ブラウザー・ブラウザー自動操作ツールは導入しません。

自動検証の対象は、固定刻みの世界更新、同一seedの再現性、15/30/60fpsでの速度一致、端・障害物、停止・復帰時計、アトラス、素材台帳、描画関数です。**シミュレーション30分のテストは、実ブラウザーでの30分間の負荷計測とは別です。** 実機の画面・操作・発熱は[手動確認](<docs/current_status.md#手動で確認すること>)が必要です。

## 構成

- [world](<src/world/world.ts>): ブラウザーから独立した60Hzの状態遷移。描画中の乱数消費なし。
- [renderer](<src/render/renderer.ts>): Canvas 2D、静的背景キャッシュ、48×64pxスプライト、低密度の光粒。
- [Web](<src/app-web/main.ts>): 表示・停止・OS設定・クレジット。通常30fps、省電力15fps。
- [素材台帳](<assets/manifest.json>): 全画像とアトラスの作者、元データ、許諾状態、改変、SHA-256。
- [編集可能な素材ソース](<scripts/generate-art.mjs>): 外部素材を使わない整数座標のプログラム描画。編集後は `npm run assets:generate`、確認は `npm run assets:check`。

論理座標480×270の安全領域を中心に保ち、別の画面比率では周囲の壁・床を拡張します。ピクセルは補間しません。画像読込失敗時には静止背景と画面内の案内へフォールバックします。
