# くじらの散歩道

夕暮れの海を望む小さな書斎で、DeepSeekちゃんをモチーフにしたクジラ娘が歩き、立ち止まり、ときどき眠る。音のない、眺めるための壁紙アプリ（Web／Mac）です。広い画面では書斎の続きが左右へ静かに広がり、海面のきらめきや光の粒がゆっくり動きます。背景は「夕凪」「月夜」「雨音」「朝凪」「雪あかり」の5つから切り替えられます。

**Web版は hazakura.dev/kujira/ 向け、Mac版は個人用ローカル試作です。Build 19では「リュミエとゆっくり対戦」と「手動で3連戦」を追加・復元しました。個人用ビルドは従来どおりアドホック署名・非配布。一般配布向け（Developer ID署名・Apple公証）はDMG・Draft Release準備済み。公開指示待ちで、privateリポジトリのままでは一般ユーザーはダウンロードできない（[参照](<docs/macos-public-release.md>)）。**

モードは「書斎で過ごす」「リュミエとゆっくり対戦」「手動で3連戦」。ゆっくり対戦はテラスの固定カメラでリュミエだけを相手に、HP表示・スコア・勝敗なしで戦い続けます。主人公は単発攻撃の間に約2〜3秒休み、リュミエも通常より長く間を置きます。打ち合った後は、両キャラが後ろ跳び・後ろ歩き・背を向けた歩行で離れ、一呼吸してから近づきます。Macでは壁紙OFF時だけ手動対戦ができ、壁紙ONにすると選んでいた書斎／ゆっくり対戦へ戻ります。Webは手動対戦に対応します。矢印/WASDで移動、Jで攻撃、Kで回避、Lで必殺技、Escで一時停止。Webには画面下の操作ボタンもあります。最新の検証と未確認項目は[現在の状態](docs/current_status.md)を参照してください。

ローカル制作版には、承認済みのヒレ耳つき基準絵から制作した**80×112px・16コマ**と、画像生成した夕景の書斎を統合しています。生成素材はGit対象外で、素材のないクリーンなチェックアウトは従来の再現可能な仮素材へ切り替わります。両者を混同しないでください。

生活モーションを強化し、承認済み16コマを上書きせず**専用24キー・6種類の仕草**を追加しました。ぴょこんと跳ねる、くすくす笑う、小さく踊る、照れて覗きながら手を振る、のびをする、自分の尾と戯れる。表情・手足・髪・尾が変わる生成キーを、予備動作→演技→戻りの間で表示します。起きている間は平均約14〜17秒の目安（歩行・睡眠を優先するため固定間隔ではありません）。ローカルBuild14で利用でき、公開済みBuild13には含まれません。連続動作の実機受け入れは未実施です。[アート方針](<docs/art-direction.md>)／[Build14の変更点とソースタグ](<docs/release-notes-life-motion-build14.md>)。生成素材・アプリ本体はソースGitに含めません。

通常の待機中には、綴星リュミエ・汐見のリツカ・紙灯のユメが1人ずつ静かに訪れ、歩いて立ち止まり、会釈して帰ります。戦闘のない来客演出です。リツカ／ユメはシルエットから描き直したコード描画に加え、GPT Imageの8姿勢アートもローカル生成しました（公開・再配布・Mac同梱は未許諾）。初回は待機時間約75〜105秒、以降は帰ってから約2〜3分。[静かな来客の仕様](docs/quiet-visitors.md)。

書斎の背景は計5種類（夕凪・月夜・雨音・朝凪・雪あかり）。各480×270pxと1024×576pxのワイドマットをローカル制作版に組み込んでいます。[追加背景の仕様](docs/background-additions.md)。

## 対戦機能について（Build 19時点）

Build 17までお蔵入りだった対戦機能は、2026-11-17のユーザー指示により**壁紙OFF面だけで復元**されました。現在の構成は次の3つです。

- **書斎で過ごす**: 従来の静かな生活・来客。対戦なし。
- **リュミエとゆっくり対戦**（壁紙ON可）: 固定テラスでリュミエ1人と打ち合い続ける眺める専用モード。HP・スコア・勝敗なし、双方倒れません。
- **手動で3連戦**（壁紙OFF時のみ）: 雑魚2ラウンド＋リュミエの90秒・SCORE・RANKあり。壁紙をONにすると選んでいたモードへ戻ります。

一方、**自動対戦イベント・エンドレスボスラッシュ・DSH API・「呼んでみる」**は引き続きお蔵入りで、ボタン・説明・関連設定は画面から撤去済みです。戦闘エンジン・描画・回帰テスト（[fighters](<src/fighters/game.ts>)、[fighters-mvp](<docs/fighters-mvp.md>)、[endless-boss-rush](<docs/endless-boss-rush.md>)）は内部検証用としてコードベースに残しています。

## Mac版

個人用の単体アプリをビルドできます。AppKit／CoreGraphics／JavaScriptCoreを使い、TypeScriptの世界と描画コマンドをWeb版と共有します。壁紙は接続中のすべてのディスプレイへ同期表示し、それぞれの解像度に合わせて1ドットを整数倍（2倍以上）で描きます。16:9以外の画面では1024×576pxのワイドマットから部屋の続きを表示するため、横長画面でも端が引き伸ばされません。背景はツールバーまたはメニューバーの「背景」から夕凪・月夜・雨音・朝凪・雪あかりを切り替えられ、選択は次回起動時にも復元されます。メニューバーの「くじら」は壁紙ON・一時停止の状態を表示し、メニューを開いている間は風景も一休みします。アプリ実行時にNode・Webサーバー・ネット接続は不要です。

```sh
# 既存のSwift 6.2+とmacOS SDKを使用。追加依存の自動導入なし。
npm run mac:build -- --local-preview
# 生成素材のない環境では、明示的な初期仮素材版
npm run mac:build -- --placeholder
```

アプリとZIPはGit対象外の一意な出力先に作り、場所とSHA-256を表示します。初回はプレビューだけ開き、「壁紙にする」で接続中のすべてのディスプレイに表示します。OFF・終了はアプリの下層ウィンドウを閉じるだけで、元の壁紙設定は変更しません。ログイン自動起動も登録しません。

**Apple Silicon向けの個人用試作・未公証です。** 署名・同梱素材・展開後の単体起動は検証しますが、可視アニメーション・Space・実機スリープ・長時間負荷の受け入れは別です。[Mac版のビルドと操作手順](<docs/macos.md>)を参照してください。

非公開リポジトリの**個人テスト用リリース**に、他のMacで試せるDMGとZIPを添付しています。一般公開リリースではありません。最新は[全ディスプレイ同期 Build 15](<https://github.com/lero003/deepseek-chan-wallpaper/releases/tag/multi-display-build15-dmg>)。DMGの取得・起動・Gatekeeper・制限は[リリースDMGの試用](<docs/dmg-release.md>)を参照してください。

**一般配布リリース（準備完了・未公開）**: `npm run mac:release` で、Developer ID署名・Hardened Runtime・Secure Timestamp・Apple公証・staple・Gatekeeper検証（DMG内・コピー後両方）・SHA-256・manifestまでを1回で再現できます。素材の許諾は所有者確認済み。公開（Publish）は所有者の明示的な指示待ちです。[一般配布リリースの準備状態と公開前確認](<docs/macos-public-release.md>)を参照してください。

## Web版の起動

Node.js 22.18以上とnpmを使用します。検証環境はNode 26.12.1。実行時の外部ライブラリはなく、開発用依存はTypeScriptとViteのみです。

初回は依存定義・lockfile・scriptsを確認し、このプロジェクト内の依存だけを導入します。インストール時のライフサイクルスクリプトは実行しません。

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run dev
```

開発用: <http://127.0.0.1:5173/>。静的ビルドの確認:

```sh
npm run build
npm run preview
```

プレビュー: <http://127.0.0.1:4173/>。どちらもループバック限定・固定ポートです。ポートが使用中なら勝手に別ポートへ移りません。終了は実行中のターミナルで `Ctrl+C`。ビルドを直接 `file://` で開くのではなく、HTTPで確認してください。

## Web版の操作と動き

- 待機・歩行・振り向き・睡眠を自律的に行います。「一時停止／再開」で停止できます。シーン下のキャプションが、いまの過ごし方を小さく伝えます。
- 「設定・作品について」に、静止表示・15fps省電力の設定と、作品のクレジットがあります。開いている間も風景は停止します。
- 海面のきらめき、窓辺の光の粒、ランプの明滅、ときどき窓を横切る小鳥がゆっくり動きます。演出は背景ごとで、夕凪は暖色と小鳥、月夜は冷色の光ときれいな流れ星、雨音は窓の外の雨筋と水面の波紋（いずれもコード描画で、承認済みの背景画像は不変）。「背景」で夕凪・月夜・雨音・朝凪・雪あかりを選べます（「雨音」は雨の景色で、音は鳴りません）。通常30fps／省電力15fps。移動は60Hz固定更新なので描画頻度で速さが変わりません。静止画・省電力・背景の3設定は、このブラウザーの中だけに保存されます（Mac版も同じ3設定）。
- ときどき窓辺まで歩いて長く佇み、眠ると小さな泡が浮かび、月夜は眠りやすく・雨音は窓辺で過ごしやすくなります。さらに6種類の仕草を偏らない順番で演じ、ときどき軽い足取りで歩きます。ローカル版の専用24キーは別シートで、既存16コマ・衝突幅・基礎の生活リズムは不変です。画像のない版や読込失敗時は元のコマによる控えめな動作へ戻ります。
- タブ非表示・ページ凍結ではタイマーを止め、大きな復帰差分を破棄します。手動停止は勝手に解除しません。
- OSの「視差効果を減らす」では静止表示です。macOS低電力モードそのものを検出しているわけではありません。
- URLの `?seed=好きな文字列` で行動を再現できます。データ収集、音声、通知、API接続、外部フォントはありません。

## アートの切り替え

[選択処理](<scripts/art-selection.mjs>)がローカル制作版の有無を確認し、Viteのエイリアスで[既定プロファイル](<src/app-web/default-art.ts>)かローカル版を選びます。未同梱ファイルへの静的importでクリーンな環境を壊さない構成です。

| 構成 | 内容 | Git |
| --- | --- | --- |
| 既定版 | 再現可能な48×64pxの初期仮キャラと背景 | 対象 |
| ローカル制作版 | 80×112pxの16コマ、足元アンカー40/108、共有80色、夕景背景480×270px | 対象外 |
| ワイドマット | 1024×576px。中央480×270pxは制作版と同一で、周囲だけ部屋の続き | 対象外 |
| 追加背景（月夜・雨音） | 同じ構図を参照して生成した480×270pxの背景と、それぞれの1024×576pxマット | 対象外 |
| ボス制作案 | 綴星リュミエ・汐見のリツカ・紙灯のユメの8姿勢・透過シート。明示的なローカルプレビュー専用 | 対象外 |
| 基準絵・生成マスター・加工元・レビュー・QA画像 | ローカル制作と検証のための資料 | 対象外 |

制作版の接触範囲はキャラ幅に合わせて拡張し、待機時のまばたきは目の画素だけを120ms変えます。歩行6コマは踏み替えと腕・裾の変化がある生成キー姿勢から整列し、睡眠4コマは2つの寝姿と接地した呼吸差分です。左右方向は反転表示なので、非対称の髪飾りも左右反転します。

壁紙は各ディスプレイのピクセル数から整数倍率を選び、ワイドマットの中央に制作版の部屋を原寸で置きます。幅が足りない狭いプレビューだけは、部屋が小さくなりすぎないよう比率でフィットさせます。画面比率が違うとワイドマットで壁・床を拡張します。追加背景は承認済みの構図を参照して画像生成し、同じ処理で480×270px・192色とワイドマットにしています。nearest-neighbor描画でぼかしません。

`--mode placeholder` を指定したビルドはローカル素材が存在しても既定版を選びます。**通常のローカルビルドには未公開素材が含まれるため、その出力を公開しないでください。**

## 検証

```sh
npm run check
npm run build
```

型検査、Node標準テスト、[既定素材の再現性検証](<scripts/generate-art.mjs>)を行います。直近の件数と実行結果は[現在の状態](<docs/current_status.md>)に記録します。ローカル素材があれば透過・接地・フレーム・共有色数・まばたきの局所性・SHA-256も検証します。ローカル画像検証は、素材がない環境ではskipになります。

[ネイティブWebKitスモーク](<tools/webkit-smoke.swift>)も使用できます。既存macOSのAppKit/WebKitとSwift 6.2以上を使い、ブラウザーや外部の自動操作パッケージをダウンロードしません。描画検証中はテスト用ウィンドウが数秒間表示されます。クリックは透過し、入力フォーカスは奪わず、終了時に閉じます。非表示時の停止は別に検証します。Webサイトデータは非永続で、通常のブラウザープロファイルは使用しません。

```sh
mkdir -p private-art/qa
swiftc -swift-version 6 -strict-concurrency=complete -parse-as-library tools/webkit-smoke.swift -o private-art/qa/webkit-smoke
private-art/qa/webkit-smoke http://127.0.0.1:4173/ private-art/qa
```

このスモークはローカル制作版と可視の対話デスクトップ環境が対象です。描画・一時停止・静止・15fps・モーダル・フォーカス復帰・狭幅／超横長・JavaScriptエラーを検査します。環境がテスト窓をhidden／occludedと判定すると可視前提の検査は失敗します。現在その可視検査は未完了で、非表示停止を無効化して合格させることはしません。**Safari／Chromeでの手動確認、実機スリープ復帰、30分間のCPU・発熱計測とは別です。** シミュレーション30分のテストも実時間の負荷試験ではありません。[未確認事項](<docs/current_status.md#残る実機確認>)を参照してください。

Playwright・専用ブラウザー・一時実行による自動導入は行いません。

## 構成と制作元

- [world](<src/world/world.ts>): seed・60Hz固定更新・状態遷移・可変のキャラ幅に対応する衝突範囲。
- [renderer](<src/render/renderer.ts>): 背景キャッシュ、ワイドマット合成、整数倍のピクセルグリッド。描画中の乱数消費・世界状態変更なし。
- [ambience](<src/render/ambience.ts>): 海面のきらめき・光の粒・ランプの明滅・小鳥。CanvasとCoreGraphicsが同じ矩形コマンドを消費します。
- [Fighters](<src/fighters/game.ts>): 生活リズムの進行を担う共有コア（お蔵入り後も engine は稼働。自動対戦は off）。戦闘・敵AI・演出進行・描画のモジュールと回帰テストは内部検証用に残置。
- [atlas](<src/render/atlas.ts>): 16フレーム、足元、フレーム別の表示時間。
- [Web](<src/app-web/main.ts>): 表示・停止・OS設定・プロファイル別クレジット。
- [既定素材台帳](<assets/manifest.json>)と[既定素材生成元](<scripts/generate-art.mjs>): クリーンな環境で使う初期仮素材。`npm run assets:generate` はこの既定版だけを再生成します。

ローカル制作版は、保存済みの生成マスターから透過処理・整列・減色・局所的な呼吸／まばたきを作る画像処理スクリプトと、別の素材台帳を持ちます。画像生成自体の再現を保証するものではありません。Pythonを使う場合は既存のPillow/numpyを備えた環境を選び、自動インストールしないでください。[アート方針](<docs/art-direction.md>)に識別点と品質判断を記録しています。
